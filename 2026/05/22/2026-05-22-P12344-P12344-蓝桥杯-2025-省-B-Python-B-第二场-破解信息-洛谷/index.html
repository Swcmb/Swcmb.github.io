[洛谷 P12344] 字符串中的最大回文子序列 + 核心优化技巧

题目概览

题目来源: 洛谷

题目难度: ★★★☆☆

标签分类: 算法标签、字符串处理标签

核心考点: 字符串处理、回文子序列、字典序最大

题意解析

给定一个仅包含小写字母的字符串 ( S )，我们需要找出其字典序最大的回文子序列。子序列可以不连续，但要保持原顺序；回文指正读反读相同；字典序比较时先看第一个不同字符的大小，若前缀相同则更长的字符串更大。

输入格式: 输入一个字符串 ( S )，长度不超过 10^5。

输出格式: 输出一个字符串，表示字典序最大的回文子序列。

样例分析:

  • 输入: abab

    • 最大字符是 'b'，出现 2 次。
    • 输出: bb

  • 输入: abcd

    • 最大字符 'd'，出现 1 次。
    • 输出: d

算法思路

4.1 问题分析

问题的本质是找到字符串 ( S ) 中字典序最大的回文子序列。关键观察点包括：

  • 字符串中字符的ASCII码大小。
  • 字符串中字符出现的次数。

数据范围对算法选择的影响主要体现在处理大规模数据时的时间复杂度。

4.2 算法原理

朴素思路: 直接构造回文子序列，时间复杂度为 ( O(n^2) )，空间复杂度为 ( O(1) )。

优化路径: 通过统计字符出现次数，直接构造字典序最大的回文子序列，时间复杂度为 ( O(n) )，空间复杂度为 ( O(1) ) 或 ( O(n) ) 用于存储输入。

算法选择: 选择统计字符出现次数的方法，因为它避免了构造所有可能的回文子序列，从而大大提高了效率。

核心思想: 通过统计字符出现次数，直接构造字典序最大的回文子序列。具体来说，找到字符串中ASCII码最大的字符，统计其在字符串中出现的次数，然后输出相应数量的该字符。

4.3 数学推导

由于问题本身是基于字符串处理的，不涉及复杂的数学公式推导。我们主要通过逻辑推理来证明算法的正确性。

4.4 多种解法对比

解法 时间复杂度 空间复杂度 适用场景 代码难度
解法1 O(n) O(1) 小规模数据 简单
解法2 O(n log n) O(n) 中等规模 中等

5.2 逐行解析

  • s = input().strip(): 读取输入字符串并去除两端空白字符。
  • max_char = max(s): 找到字符串中的最大字符。
  • cnt = s.count(max_char): 统计最大字符在字符串中出现的次数。
  • print(max_char * cnt): 输出字典序最大的回文子序列。

5.3 优化技巧

  • 空间优化：由于我们只需要存储最大字符和其出现次数，不需要额外的空间来存储子序列，因此空间复杂度为 ( O(1) )。
  • 时间优化：通过一次遍历找到最大字符并统计其出现次数，时间复杂度为 ( O(n) )。

6. 复杂度分析

时间复杂度: ( O(n) )，其中 ( n = |S| )。

空间复杂度: ( O(1) ) 或 ( O(n) )，取决于是否需要额外存储输入字符串。
