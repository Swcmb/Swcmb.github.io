蓝桥杯国赛 B 组 — 考前终极指导

核心策略重申：最常规的模拟 + 最简单的贪心 + 最朴素的枚举 + 所有题的 DFS 部分分 + BFS ≥ 国二

一、高效复习建议

1.1 你的能力画像（基于对 ~80 道已分类题目的深度分析）

领域 熟练度 判据
DFS/回溯 ⭐⭐⭐⭐⭐ 绝对强项。子集/排列/组合三大枚举模板化程度极高，剪枝意识好（烤鸡、飞机降落）
贪心算法 ⭐⭐⭐⭐ 排序贪心、差值转化、双指针三大模式掌握扎实（三国游戏、翻硬币）
模拟/实现 ⭐⭐⭐⭐ 复杂规则模拟能力强（赢球票、交易账本），但简单题注释不足
DP（基础） ⭐⭐⭐⭐ 01背包、完全背包、LCS、区间DP模板正确，但缺状压/数位/树形DP
BFS ⭐⭐ 最大弱点！ 仅练过观星、扫雷，且多作为DFS替代使用，需考前重点默写模板
图论（进阶） ⭐ 缺Dijkstra、拓扑排序、并查集等核心算法

1.2 今晚时间表（严格执行）

时间段 时长 内容 要点
19:00-20:00 60min 精读本文模板章节（第三章），逐行确认理解 遇疑问先记下，不纠结
20:00-21:30 90min 复盘8道精选题目（第二章列表），不看代码先想做法，再看代码验证 每题写下1-2句核心思路
21:30-22:00 30min BFS专项强化：默写BFS模板（网格+状态+多源），回顾观星/扫雷代码 这是你最大的弱点，必须补！
22:00-22:15 15min 快速过Python竞赛配置（递归深度、快速IO、lru_cache） 防止低级RE
22:15后 — 停止学习，放松大脑，保证≥7小时睡眠 疲劳比少复习更致命
明早 7:30-8:00 30min 浏览本文”考场策略”章节，预热思维
明早 8:00-考前 灵活 默写DFS三件套+BFS模板一遍，确认手指记忆 轻度预热即可

如果时间紧张：优先完成核心最低要求——阅读模板(10min) + 复盘题目(40min) + 默写DFS(15min) + 默写BFS(15min) + 浏览DP/前缀和(10min) + 文档汇总 = ~110min。BFS专项强化和Python配置可酌情裁剪。

1.3 考场4小时作战方案

时间段 内容 作战指令
0-20min 通读全卷，标记难度，区分填空/编程题 深呼吸，不急不躁
20-60min 先做所有简单题（模拟、基础枚举、双指针、基础贪心） 这是送分题，一道不能丢
60-120min 做中等题，优先用DFS/BFS/贪心攻破 ⚠️ 卡题应对：思考≤15分钟无果 → 立即标记 → 跳下一题 → DFS阶段回头处理
120-180min DFS暴力打所有难题的部分分（特别是小数据范围）；回头处理标记的卡住题目 哪怕n≤10只拿20%的分也要拿！
180-210min 未完成题目扫尾 + 检查边界（数组越界、极端输入、int溢出）
210-240min 最终检查：文件名、输出格式、样例复测 别因为格式丢分

1.4 考场上看到一道题的决策树

1.5 得分预期

题型 预期得分 策略
填空题 满分 Python暴力计算+数学推导
简单编程题（模拟/贪心/枚举） 满分 不能丢分
中等编程题（DFS/BFS/基础DP） 80%+ DFS模板拿满，较难部分尝试优化
难题（图论/高级DP） 30-50% DFS打小数据部分分，不恋战

核心理念：国二不是把题”做完”，而是”把能做的做对 + 每道题都拿点分”。

3. P13887 三国游戏（贪心 ⭐⭐⭐⭐⭐）

文件：d:\CPCode\py\P_13887_蓝桥杯_2023_省_Python_A_三国游戏.py

贪心分析的教科书。”A赢过B+C” → 转化为一维差值 s = A_i - B_i - C_i，排序后贪心累加。这种差值转化法可迁移到所有博弈/比较类题目。代码注释详尽，含贪心正确性分析。

4. P8641 赢球票（模拟 ⭐⭐⭐⭐）

复杂模拟的代表。环状数组遍历 + 条件判断 + 状态维护的完整训练。国赛常出规则复杂的模拟题，这道题的代码结构是优秀参考。

5. P8597 翻硬币（贪心+差分 ⭐⭐⭐⭐）

文件：d:\CPCode\py\P_8597_蓝桥杯_2013_省_B_翻硬币.py

代码仅约10行，但思维极其精巧：从左到右单向扫描，遇到不同就翻当前和下一个硬币。考场上遇到相邻操作题，优先想到这个模式。

6. P6566 观星（BFS ⭐⭐⭐⭐⭐）

文件：d:\CPCode\py\P_6566_NOI_Online_3_入门组_观星.py

BFS连通块计数的标准模板。deque做队列，8方向搜索，哈希表统计连通块大小。代码有详细注释，是你BFS复习的最佳材料。

选看（2道提分题）

7. P12135 水质检测（DP） — “闫氏DP分析法”注释是DP思维顶级训练，2×n网格连通性DP的状态设计（3种列状态）可复用。

8. P8649 k倍区间（前缀和+同余） — (prefix[r] - prefix[l-1]) % k == 0 ⇒ prefix[r] % k == prefix[l-1] % k 这个同余推导是蓝桥杯高频考点。

最后的提醒

  1. DFS三件套 + BFS模板必须在明天考前默写一遍——这是你的核心武器
  2. 卡题15分钟无思路就跳——别让一道题吃掉半小时
