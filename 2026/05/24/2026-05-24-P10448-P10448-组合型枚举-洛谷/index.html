P10448 - P10448 组合型枚举 - 洛谷

发表于 2026-05-24

算法名称：组合型枚举

核心优化技巧

在解决这类问题时，我们通常需要遍历所有可能的组合，并检查它们是否满足条件。为了提高效率，我们可以采用以下策略：

  1. 剪枝：在遍历过程中，如果某个组合已经满足条件，那么我们就可以直接返回结果，而不需要继续检查其他组合。
  2. 动态规划：如果我们已经找到了一个解，那么这个解就可以作为子问题的解，从而避免重复计算。

解题思路

问题分析

  • 问题描述：给定一个整数数组 nums 和一个目标值 target，我们需要从数组中选择若干个数字，使得它们的和等于 target。
  • 输入格式：整数数组 nums 的长度为 n，目标值 target 是一个整数。
  • 输出格式：一个整数数组，表示选择的数字。

算法原理

  • 朴素思路：遍历数组，对于每个元素，尝试将其添加到当前和中，直到和等于 target 或者遍历完所有元素。
  • 优化路径：使用动态规划的思想，将之前计算过的结果存储起来，避免重复计算。
  • 核心思想：通过剪枝和动态规划，减少不必要的计算，提高算法的效率。

数学推导

假设我们已经计算出了前 i 个元素的和为 sum_i，那么第 i+1 个元素的和为 target - sum_i。因此，我们只需要检查是否存在一个索引 j，使得 nums[j] + sum_i == target - sum_i。

多种解法对比

解法 时间复杂度 空间复杂度 适用场景 代码难度
解法1 O(n^2) O(n) 小规模数据 简单
解法2 O(n^2) O(n) 中等规模 中等

代码详解

复杂度分析

  • 时间复杂度：O(n^2)，其中 n 是数组 nums 的长度。
  • 空间复杂度：O(n)，用于存储动态规划的数组。
  • 复杂度对比：与简单的暴力解法相比，本算法的时间复杂度更高，但空间复杂度更低。
