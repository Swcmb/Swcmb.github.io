二、输入语句

Java 中获取键盘输入通常使用 java.util.Scanner 类。

2.1 Scanner 使用步骤

使用 Scanner 获取键盘输入通常遵循以下四个步骤：

  1. 导包：import java.util.Scanner;
  2. 创建对象：Scanner scanner = new Scanner(System.in);
  3. 获取数据：调用 next() 或 nextXxx() 方法。
  4. 释放资源：scanner.close(); （养成良好习惯，防止资源泄露）

2.3 next() 与 nextLine() 的区别

在获取字符串时，需特别注意 next() 和 nextLine() 的区别：

  • next()：
    • 一定要读取到有效字符后才可以结束输入。
    • 对输入有效字符之前遇到的空白，next() 会自动将其去掉。
    • 不能得到带有空格的字符串（遇到空格即停止读取）。
  • nextLine()：
    • 以 Enter 键作为结束符。
    • 返回的是回车之前的所有字符，可以获得包含空格的字符串。

建议在处理包含空格的文本输入时（如详细地址），优先使用 nextLine()。

总结：掌握 Java 的输入输出是编程的基础。println 和 print 适用于简单显示，printf 适用于格式化需求；Scanner 则是处理控制台交互的利器。注意在使用完 Scanner 后及时关闭以释放系统资源。
