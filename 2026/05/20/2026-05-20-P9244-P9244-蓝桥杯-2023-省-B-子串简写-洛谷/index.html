[洛谷 P9244] 子串简写 + 子串匹配优化详解

题目概览

  • 题目来源: 洛谷 (https://www.luogu.com.cn/problem/P9244)
  • 题目难度: ★★☆☆☆
  • 标签分类: 字符串处理、枚举
  • 核心考点: 子串匹配、枚举优化

题意解析

  • 问题描述: 给定一个字符串 s 和两个字符 c1、c2，找出所有以 c1 开头，以 c2 结尾的子串，并输出这些子串的数量。
  • 输入格式: 第一行输入一个整数 k，表示子串长度；第二行输入字符串 s，第三行输入两个字符 c1 和 c2。
  • 输出格式: 输出一个整数，表示满足条件的子串数量。
  • 样例分析:
    • 输入: 3 abcabcabc a c
    • 输出: 3
    • 解释: 子串 “abc”, “bca”, “cab” 满足条件。

算法思路

4.1 问题分析

  • 问题的本质是寻找特定模式的子串。
  • 关键观察点：子串长度固定，且以特定字符开头和结尾。
  • 数据范围对算法选择的影响：字符串长度和子串长度可能较大，但子串数量相对较少。

4.2 算法原理

  • 朴素思路: 遍历所有可能的子串，检查是否满足条件。时间复杂度为 O(n^2)。
  • 优化路径: 通过枚举的方式，直接定位到以 c1 开头，以 c2 结尾的子串，避免不必要的检查。
  • 算法选择: 枚举法，因为子串数量较少，枚举是可行的。
  • 核心思想: 通过固定子串的长度，直接检查每个可能的子串是否符合条件。

4.3 算法实现

4.4 代码详解

  • 核心代码段: for i in range(len(s) - k + 1): if s[i:i+k] == c1 + c2: res += 1
  • 逐行解析: 遍历所有可能的子串起始位置，检查子串是否以 c1 开头，以 c2 结尾。
  • 优化技巧: 无需额外空间，直接在原字符串上操作。

5. 复杂度分析

  • 时间复杂度: O(n)，其中 n 是字符串 s 的长度。
  • 空间复杂度: O(1)，不需要额外空间。

6. 输入输出示例

  • 样例输入: 3 abcabcabc a c
  • 样例输出: 3

7. 常见错误与调试技巧

  • 易错点: 忘记检查子串长度是否超过字符串长度。
  • 调试方法: 使用简单的测试用例，逐步增加复杂度，观察程序输出。

8. 总结与扩展

  • 核心收获: 学会了如何通过枚举的方式解决子串匹配问题。
  • 举一反三: 可以将此方法应用于其他需要匹配特定模式的字符串问题。
  • 进阶方向: 研究更高效的字符串匹配算法，如 KMP 算法、Boyer-Moore 算法等。
