🛠️ 零基础使用教程

如果您不熟悉浏览器插件的使用，请按照以下步骤操作：

第一步：安装 Tampermonkey 插件

  1. 访问Tampermonkey 官网。
  2. 根据您使用的浏览器，点击对应的下载按钮（如 Chrome Web Store、Edge Add-ons 等）。
  3. 在浏览器扩展商店页面点击“添加至浏览器”完成安装。

第二步：安装脚本

  1. 点击浏览器右上角的 Tampermonkey 扩展图标，选择“添加新脚本”。
  2. 在打开的编辑器页面中，删除默认生成的所有内容。
  3. 将上方的完整代码复制并粘贴到编辑器中。
  4. 点击左上角的“文件” -> “保存”（或按 Ctrl+S）。

第三步：运行与测试

  1. 打开教务平台登录页面 (http://zhjw.qfnu.edu.cn/jsxsd/framework/xsMain.jsp)。
  2. 确保 Tampermonkey 图标显示数字 1，表示脚本已在此页面生效。
  3. 修改时间测试：建议先修改代码中的 specifiedHours 等变量为当前时间后的一两分钟，观察页面是否自动刷新。测试成功后，再改回目标时间（如 9:00:00）。
  4. 在目标时间到达前登录系统，静待脚本自动工作。

小结

该脚本利用了最简单的轮询机制，轻量且有效。希望这个小工具能为你的学习生活带来便利，但也请务必遵守学校的各项管理规定，理性使用技术手段。
