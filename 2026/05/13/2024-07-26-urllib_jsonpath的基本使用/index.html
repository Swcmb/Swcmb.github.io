代码核心详解

1. 请求头构造

在爬取淘宝等大型网站时，直接请求通常会返回 403 Forbidden 错误。代码中我们构造了完整的 headers：

  • User-Agent：伪装成 Chrome 浏览器。
  • Referer：告诉服务器请求来自哪个页面，这是常见的防盗链措施。
  • Cookie：维持会话状态，部分接口需要用户登录信息才能返回数据。

2. urllib 的基本使用

与 requests 不同，urllib 不能直接在 urlopen 中传递 headers。我们需要先实例化一个 urllib.request.Request 对象，将 URL 和 Headers 传入，然后再使用 urlopen 发送这个请求对象。

3. JSONP 数据清洗

这是本案例的难点。淘宝电影的接口返回的并非标准的 JSON 字符串，而是 JSONP 格式。

  • 现象：返回内容包裹在 jsonp109(...) 中。
  • 处理：使用 Python 的字符串切片方法 split。
    • html.split('(')[1]：获取 jsonp109 之后的内容。
    • .split(')')[0]：去除最后的括号。
    • 最终得到纯净的 JSON 字符串。

4. 后续步骤：JsonPath 解析

虽然本文标题提及 jsonpath，但当前阶段我们完成了数据的获取与清洗。保存的 taobao.json 文件内容为标准 JSON 格式，这正是 jsonpath 库发挥作用的舞台。
