代码详解与优化点

  1. 输入处理优化：
    原代码使用了 input().split() 逐行读取，这在算法题中是常规做法。优化后的代码使用了 sys.stdin.read().split() 配合迭代器，这种方式在处理大规模输入时效率更高，且代码结构更清晰。

  2. 变量命名规范化：
    将原代码中的 a, b, k, l 等单字母变量名修改为更具语义的 image, result, ni (neighbor_i), nj (neighbor_j)，提高了代码的可读性。

  3. 逻辑结构清晰化：
    在内层循环中，显式地使用了偏移量 di 和 dj（取值 -1, 0, 1），这比 range(i-1, i+2) 这种写法在逻辑上更直观地表达了“周围邻居”的概念，同时保留了边界检查 if 0 <= ni < n，确保了程序的健壮性。

  4. 核心逻辑保持：
    算法核心依然是模拟卷积过程，使用 total_sum 累加邻域值，pixel_count 动态统计有效像素数量，最后利用 Python 的整除运算符 // 实现向下取整，与原题逻辑完全一致。
