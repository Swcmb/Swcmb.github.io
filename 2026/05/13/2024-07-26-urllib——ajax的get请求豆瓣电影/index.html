2. Ajax 接口特性

与请求普通 HTML 页面不同，Ajax 接口直接返回 JSON 格式的数据。

  • URL 特点：通常以 /j/ 开头或返回数据非 HTML。
  • 数据解析：获取到的 html 变量实际上是 JSON 字符串，后续可使用 json.loads(html) 解析为 Python 字典进行深度清洗。

3. 编码处理

网络传输的数据为字节流，必须调用 decode('utf-8') 将其解码为字符串，否则写入文件后会出现乱码或无法阅读的情况。
