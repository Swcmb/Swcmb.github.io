常用元素定位方法详解

以下代码演示了八种核心定位方式。请注意区分 find_element（查找单个元素）与 find_elements（查找多个元素，返回列表）的区别。

1. 初始化浏览器

首先，我们需要启动浏览器并打开目标页面。

2. ID 定位

ID 是页面上元素的唯一标识，通常定位速度最快且最准确。

3. NAME 定位

NAME 属性通常用于表单元素，定位方式与 ID 类似。

4. XPATH 定位

XPath 是一种强大的路径定位语言，几乎可以定位页面上的任何元素。

5. TAG_NAME 定位

通过标签名（如 input, div, a）定位。由于页面中同类标签通常很多，一般配合 find_elements 使用。

6. CSS_SELECTOR 定位

CSS 选择器定位速度快，语法简洁，是常用的定位方式之一。

7. LINK_TEXT 定位

专门用于定位超链接 <a> 标签，通过链接的完整文本内容进行匹配。

8. 保持会话

在脚本执行完毕前，添加输入暂停，防止浏览器立即关闭，便于观察结果。
