前言

在进行网络数据采集时，图片资源下载是最常见的需求之一。本文将以“站长素材”为例，使用Python内置的 urllib 库配合 lxml 库，演示如何构建一个多页图片爬虫。

本案例的核心技术点包括：

  1. 请求伪装：设置 User-Agent 模拟浏览器访问。
  2. 懒加载处理：解析 data-original 属性获取真实图片地址。
  3. 文件下载：使用 urllib.request.urlretrieve 高效保存图片。

网站结构分析

在编写代码前，我们需要分析目标网站的URL规律和页面结构。

1. URL规律

目标网站的分页结构通常如下：

  • 第1页：https://sc.chinaz.com/tupian/rentiyishu.html
  • 第2页及以后：https://sc.chinaz.com/tupian/rentiyishu_2.html

因此，在构建请求时需要单独处理首页逻辑。

2. 图片懒加载

为了提升网页加载速度，该网站使用了图片懒加载技术。在浏览器F12检查元素时，你会发现：

  • src 属性往往是一个占位符或未加载状态。
  • 真实的图片地址存储在 data-original 属性中。

我们需要使用 XPath 提取该属性的值，并补全协议头（通常为 https:）。

代码实现

以下是完整的爬虫代码实现。请确保本地已安装 lxml 库（pip install lxml），urllib 为 Python 标准库，无需额外安装。

代码详解

1. 请求构建 (create_request)

为了让爬虫看起来像正常的浏览器访问，我们必须在请求头中添加 User-Agent 字段。如果不添加，很多网站会拒绝服务（返回403错误）。

2. 内容获取 (get_content)

使用 urllib.request.urlopen 发送请求，并调用 read() 方法读取二进制数据，最后通过 decode('utf-8') 转换为字符串以便后续解析。

3. 图片解析与下载 (download_images)

这是核心逻辑所在：

  • XPath 定位：我们定位到 class="lazy" 的 img 标签。之所以找这个类名，是因为很多前端懒加载库默认会使用该类名，或者网站开发者自定义了此类名。
  • 提取属性：使用 @data-original 获取真实图片URL，@alt 获取图片描述作为文件名。
  • URL 处理：提取出来的链接通常是 //sc.chinaz.com/... 格式，缺少协议头，需手动拼接 https:。
  • 异常处理：网络请求随时可能失败，使用 try-except 捕获异常可以确保某张图片下载失败不会导致整个程序崩溃。

4. 目录处理优化

原代码中直接硬编码了路径 ./img/，如果该目录不存在，程序会报错。我在优化后的代码中增加了 os.makedirs 检查，增强了代码的健壮性。

总结

本文展示了如何使用 Python 标准库 urllib 编写一个简易的图片爬虫。相比于第三方库 requests，urllib 无需安装，适合对第三方依赖有限制的环境。

在实际项目中，建议进一步优化：

  1. 增加多线程/多进程下载，提升效率。
  2. 优化文件名去重逻辑，避免重名覆盖。
