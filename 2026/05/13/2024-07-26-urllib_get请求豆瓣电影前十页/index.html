二、 代码实现

在明确了逻辑后，我们采用模块化设计的思路，将功能拆分为 下载页面、解析保存 和 主流程控制 三个部分。

三、 核心技术点解析

1. UA伪装（User-Agent）

豆瓣对于爬虫请求有一定的限制。如果在请求头中不包含 User-Agent，服务器可能会拒绝访问或返回错误数据。
代码中通过 urllib.request.Request 对象的 headers 参数，将请求伪装成 Chrome 浏览器，这是爬虫开发中最基础也是最重要的步骤。

2. urllib 的基本使用流程

相比于 requests 库，urllib 作为标准库，其调用链稍显繁琐，但在无第三方库环境下是首选：

  1. 构建 Request 对象（包含 URL 和 Headers）。
  2. 使用 urlopen() 发送请求。
  3. 调用 read() 读取二进制流。
  4. 使用 decode() 解码为字符串。

3. 数据存储

本例中接口直接返回的是 JSON 格式的字符串，因此我们可以直接将 html 内容写入 .json 文件，无需额外的解析步骤（如 XPath 或 BeautifulSoup），大大简化了流程。

四、 总结

本文通过一个简单的实战案例，演示了如何利用 urllib 进行分页数据的抓取。关键在于分析 URL 参数的变化规律以及正确设置请求头。对于更复杂的场景，建议后续学习 requests 库以及更高级的反爬策略。

注意：爬虫运行时请遵守网站的 robots.txt 协议，并控制请求频率，避免对服务器造成过大压力。
