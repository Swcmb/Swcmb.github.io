解题思路：贪心与平衡三进制

1. 核心分析

这是一道经典的贪心算法题目，其本质与平衡三进制（Ternary Numeral System）有关。

题目要求砝码数量最少，且砝码可以放在天平两端。假设我们已经有一组砝码，它们能称出的最大连续重量为 $S$。

当我们新增一个砝码 $w$ 时，由于天平两边都可以放，新的称重范围会有以下三种情况：

  1. 砝码全在一边：$w + [1, S]$ $\rightarrow$ 范围 $[w+1, w+S]$
  2. 砝码在另一边（做减法）：$w - [1, S]$ $\rightarrow$ 范围 $[w-S, w-1]$
  3. 不使用该砝码：$[1, S]$

为了让新范围能够与旧范围 $[1, S]$ 无缝衔接，并最大化称重上限，我们需要满足两个条件：

  1. 无缝衔接：减法范围的上限应紧接原范围的下限（或重叠），即 $(w - 1)$ 应该等于 $S$（或 $S+1$，为求连续性，取 $w - 1 = S \implies w = S + 1$）。但这样会造成浪费。

    实际上，为了让范围 $[w-S, w-1]$ 与 $[1, S]$ 连接，我们至少需要 $w - S \le S + 1$（即新范围的最小值不能比旧范围最大值大太多）。为了最大化新范围，我们取临界条件：

2. 推导过程

设当前砝码组合能称出的最大连续重量为 $S$。

  • 初始状态：$S = 0$。
  • 第一枚砝码：为了称重 1，只能选 $w_1 = 1$。此时能称重范围 $[1, 1]$，最大值 $S_1 = 1$。
  • 第二枚砝码：为了扩展范围，最优选择 $w_2 = 2S_1 + 1 = 3$。
    • 新范围：$[3-1, 3+1] = [2, 4]$ 与 $[1, 1]$ 合并为 $[1, 4]$。
    • 此时 $S_2 = 1 + 3 = 4$。
  • 第三枚砝码：最优选择 $w_3 = 2S_2 + 1 = 9$。
    • 新范围：$[9-4, 9+4] = [5, 13]$ 与 $[1, 4]$ 合并为 $[1, 13]$。
    • 此时 $S_3 = 4 + 9 = 13$。

3. 算法实现

我们需要找到最小的 $k$，使得 $S_k \ge N$。
直接迭代计算即可：

  1. 初始化最大重量 $S = 0$，砝码数量 $count = 0$。
  2. 循环条件：当 $S < N$ 时。
  3. 每次迭代：$S \leftarrow 3S + 1$，$count \leftarrow count + 1$。
  4. 输出 $count$。

  • 时间复杂度：$O(\log_3 N)$。由于 $N$ 最大为 $10^9$，而 $3^{18}$ 远大于 $10^9$，循环最多执行 19 次，效率极高。
