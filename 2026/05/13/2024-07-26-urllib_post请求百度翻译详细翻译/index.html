关键技术点解析

1. POST 请求的数据编码

在使用 urllib 发送 POST 请求时，有一个常见的坑：data 参数必须是 bytes 类型。
代码中我们执行了以下步骤：

  1. 使用字典定义参数。
  2. 使用 urllib.parse.urlencode(data) 将字典转换为 key=value&key=value 格式的字符串。
  3. 调用 .encode('utf-8') 将字符串转换为字节流。

2. 请求对象的封装

相比于直接使用 urlopen，构建 urllib.request.Request 对象的好处在于我们可以更灵活地设置 Headers。在爬虫开发中，伪装 User-Agent 和传递正确的 Cookie 是成功的关键。

3. 百度翻译的反爬机制

代码中的 sign 参数是百度翻译爬虫的一个难点。该参数是根据待翻译的文本（如 ‘love’）通过前端 JavaScript 算法计算生成的。如果 sign 值不匹配，服务器将拒绝返回正确结果。

  • 解决方案：通常需要分析百度翻译的 JS 文件，找到生成 sign 的算法并用 Python 复现，或者使用 PyExecJS 等库直接执行 JS 代码。

总结

本文通过 urllib 实现了对百度翻译 POST 接口的调用。虽然相比 requests 库，urllib 的代码略显繁琐（需手动编码数据、处理 Request 对象），但它能帮助我们深入理解 HTTP 协议的底层细节。在实际项目中，如果遇到复杂的反爬逻辑（如动态 sign 计算），建议结合 Selenium 或 Playwright 等自动化测试工具，或者深入逆向 JS 逻辑。
