核心参数解析

在构造 POST 请求时，有几个关键点需要注意：

  1. URL 参数：?from=en&to=zh 指明了翻译的方向，通常也可以放在 data 表单中，具体视接口定义而定。
  2. Headers (请求头)：
    • User-Agent：必填项，用于伪装成浏览器访问，避免被防火墙直接拦截。
    • Cookie：用于维持登录状态。许多接口（如百度翻译）在频繁访问或使用高级功能时需要登录态。
  3. Data (请求体)：
    • sign & token：这是反爬虫的核心。大多数现代网站的 API 接口会通过 JavaScript 动态生成 sign（签名）和 token。如果这些参数过期或错误，服务器将返回错误代码（如 998、999 等）。在实际爬虫开发中，通常需要逆向分析前端 JS 代码来找到生成算法。

总结

使用 requests 发送 POST 请求并不复杂，难点在于分析接口所需的参数格式和反爬策略。建议在实际开发中，优先使用浏览器开发者工具对比请求参数，确保 headers 和 data 字段的完整性与准确性。
