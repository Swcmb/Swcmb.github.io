步骤详解

  1. 构建请求头：
    百度等搜索引擎通常会检测请求头中的 User-Agent。如果不设置，Python 默认的 UA 为 Python-urllib/x.x，极易被反爬机制拦截。因此，我们需要构造字典模拟 Chrome 浏览器访问。

  2. 创建 Request 对象：
    urllib.request.Request 类允许我们将 URL、Headers、Data 等参数封装成一个独立的请求对象，便于管理。

  3. 实例化 Handler：
    handler = urllib.request.HTTPHandler() 创建了一个处理 HTTP 协议的处理器。这也是 urlopen 默认使用的处理器，显式写出是为了方便后续扩展（例如替换为支持代理的 ProxyHandler）。

  4. 构建 Opener：
    opener = urllib.request.build_opener(handler) 将处理器组装成打开器。这就好比我们将引擎装到了汽车上。

  5. 发送请求：
    opener.open(request) 最终执行请求，返回结果与 urlopen 一致，是一个类文件对象，可以使用 read() 方法读取数据。

总结

虽然本例中使用 HTTPHandler 看起来比直接使用 urlopen 代码量更多，但这套流程是进阶爬虫的基础。当你需要使用 IP 代理池或自动管理 Cookie 时，只需将 HTTPHandler 替换为 ProxyHandler 或 HTTPCookieProcessor，并同样构建 Opener 即可，具有很强的扩展性。
