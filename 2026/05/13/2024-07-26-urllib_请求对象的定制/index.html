2. 进阶案例：URL 参数编码

在实际爬虫中，我们经常需要搜索特定关键词（如中文）。URL 中如果包含中文或其他特殊字符，必须进行编码（Percent-encoding），否则会抛出错误或乱码。

urllib.parse.quote 方法可以将字符串转换为 URL 兼容的编码格式。

关键点说明：

  • urllib.parse.quote("你好")：将中文字符转换为 %xx 形式，这是 HTTP 协议传输的标准要求。
  • full_url 拼接：在爬虫开发中，构建带参数的 URL 是最常见的操作之一。

总结

本文介绍了 urllib 库中请求对象定制的关键技术：

  1. 使用 urllib.request.Request 封装 URL 和 Headers，解决 urlopen 无法携带请求头的问题。
  2. 通过设置 User-Agent 实现浏览器伪装，绕过基础的反爬检测。
  3. 使用 urllib.parse.quote 对 URL 参数进行编码，解决中文参数传输问题。

掌握这三点，即可应对绝大多数简单的网页爬取需求。
