[洛谷 P15435] 免费披萨 - 洛谷

题目概览

题目来源: 洛谷

题目难度: ★★★★☆

标签分类: 算法, 数据结构

核心考点: 本题考查了深度优先搜索（DFS）和贪心算法的应用，以及如何通过剪枝优化搜索效率。

题意解析

题目要求我们找出一种分配披萨的方式，使得每个孩子都能得到相同数量的披萨，并且使用的披萨数量最少。我们有9个孩子和10块披萨，每个孩子至少得到1块披萨。

输入格式: 输入一个整数n，表示孩子的数量（1 <= n <= 9）。

输出格式: 输出一个整数，表示最少使用的披萨数量。

样例分析: 当有3个孩子时，最优的分配方式是每个孩子得到3块披萨，总共使用9块披萨。

算法思路

4.1 问题分析

问题的本质是找到一种分配披萨的方式，使得每个孩子都能得到相同数量的披萨，并且使用的披萨数量最少。这是一个典型的贪心算法问题，通过剪枝可以有效地减少搜索空间。

4.2 算法原理

朴素思路: 最直观的解法是枚举所有可能的分配方式，然后计算每种方式的披萨数量和使用次数。但这种方法的时间复杂度过高，不适合大规模数据。

优化路径: 使用深度优先搜索（DFS）结合剪枝技术，可以有效地减少不必要的搜索。在DFS过程中，我们记录当前分配的方式和使用的披萨数量，并在发现不满足条件的情况下提前终止搜索。

算法选择: 深度优先搜索适合解决这类问题，因为它可以深入到每一个可能的分配方式中。剪枝技术则可以大大减少搜索空间，提高算法效率。

核心思想: 我们从第一个孩子开始，尝试将每一块披萨分配给这个孩子。如果当前分配方式满足条件，则继续分配下一块披萨；如果不满足条件，则回溯并尝试其他分配方式。

4.3 数学推导

由于这个问题主要是基于贪心算法和DFS，数学推导并不是主要的研究方向。我们主要关注如何通过剪枝优化搜索效率。

4.4 多种解法对比

  1. n = int(input()): 读取孩子的数量。
  2. used = [False] * 9: 初始化一个布尔数组，表示每个孩子是否已经分配到披萨。
  3. current = []: 初始化一个列表，用于存储当前分配的披萨数字。
  4. best_gcd = -1 和 best_num = 10**10: 初始化最佳公约数和最佳分配方案。
  5. def dfs(pos):: 定义DFS函数，pos表示当前分配到第几个孩子。
  6. if pos == 8:: 如果所有孩子都分配到了披萨。
  7. for ins_pos in range(9):: 尝试将每一块披萨分配给第一个孩子。
  8. for digit in range(1, 9):: 尝试将每一个数字分配给第一个孩子。
  9. arr = current[:]: 复制当前分配方案。
  10. arr.insert(ins_pos, digit): 在指定位置插入新的数字。
  11. num = int("".join(map(str, arr))): 将分配方案转换为整数。
  12. g = math.gcd(num, n): 计算当前分配方案的公约数。
  13. if g > best_gcd:: 如果当前公约数大于最佳公约数。
  14. best_gcd = g 和 best_num = num: 更新最佳公约数和最佳分配方案。
  15. elif g == best_gcd and num < best_num:: 如果当前公约数等于最佳公约数，但数字更小。
  16. best_num = num: 更新最佳分配方案。
  17. return: 返回上一层递归。
  18. for i in range(1, 9):: 尝试将每一个数字分配给第二个孩子。
  19. if not used[i]:: 如果该孩子还没有分配到披萨。
  20. used[i] = True: 标记该孩子已经分配到披萨。
  21. current.append(i): 将数字添加到当前分配方案。
  22. dfs(pos + 1): 递归调用DFS函数，处理下一个孩子。
  23. current.pop(): 回溯，移除最后一个分配的数字。
  24. used[i] = False: 回溯，标记该孩子没有分配到披萨。
  25. dfs(0): 从第一个孩子开始DFS搜索。
  26. print(best_num): 输出最佳分配方案。

5.3 优化技巧

  • 空间优化: 使用布尔数组used来记录孩子是否已经分配到披萨，避免了使用额外的数据结构。
  • 时间优化: 通过剪枝技术，提前终止不满足条件的搜索路径。

复杂度分析

时间复杂度: O(n!)，因为我们需要尝试所有可能的分配方式。

空间复杂度: O(n)，用于存储当前分配方案和递归栈。
