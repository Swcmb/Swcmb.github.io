# Graph Lab — 图论算法可视化

交互式中文网页，用动画演示 DFS、BFS、拓扑排序与 Dijkstra。

## 在线访问

https://swcmb.github.io/graph-algorithm-lab/

## 功能

- 切换 4 种图例：有向含环、有向 DAG、无向含环、无向树。
- 逐步播放、暂停、前进、后退和重置算法动画。
- 查看 DFS 递归栈、BFS 队列、拓扑序列、Dijkstra 距离表。
- 高亮当前节点、已遍历边、回路证据与最短路径树。
- 展示复杂度、算法适用范围和判环依据。
- 纯 HTML、CSS、JavaScript，无需构建工具或第三方依赖。

## 算法结论

| 算法 | 有向图判环 | 无向图判环 | 说明 |
|---|---|---|---|
| DFS | 可以 | 可以 | 有向图检查指向递归栈中节点的回边；无向图忽略父边 |
| BFS | 普通 BFS 不足 | 可以 | 无向图中检查非父节点的已访问邻居 |
| 拓扑排序 | 可以 | 不适用 | 未能处理全部节点，说明有向图含环 |
| Dijkstra | 不负责判环 | 不负责判环 | 求非负权图的单源最短路径 |
