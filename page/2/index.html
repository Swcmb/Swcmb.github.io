[洛谷 P12887] 答题数量 + 逻辑推理优化技巧

题目概览

  • 题目来源: 洛谷 (https://www.luogu.com.cn/problem/P12887)
  • 题目难度: ★★☆☆☆
  • 标签分类: 逻辑推理、字符串处理
  • 核心考点: 逻辑推理、字符串比较

题意解析

  • 问题描述: 计算在所有可能的标准答案中，小蓝最多能答对多少题。
  • 输入格式: 输入第一行包含两个整数 N 和 M，分别表示考试题数和朋友的答对题数。接下来一行包含字符串 S，表示小蓝的答案。再接下来一行包含字符串 T，表示朋友的答案。
  • 输出格式: 输出一个整数，表示小蓝最多能答对的题数。
  • 样例分析:
    • 输入: 4 2\nTTFF\nFTTF
    • 输出: 4
    • 解释: 两人答案相同的题目有第2、4题，朋友最多答对2题，所以在这两题上两人都答对。朋友剩余的2题中，他答对了1题，所以小蓝答对了3题。因此，小蓝最多能答对4题。

算法思路

4.1 问题分析

  • 本题的核心在于逻辑推理，通过比较小蓝和朋友的两串答案，计算出小蓝最多能答对的题数。
  • 关键观察点：两人答案相同的题数和不同的题数。

4.2 算法原理

  • 朴素思路: 直接遍历两串答案，比较每题的答案，计算小蓝的答对题数。
  • 优化路径: 利用逻辑推理，减少不必要的比较。
  • 算法选择: 选择逻辑推理作为主要算法，因为它能直接解决问题。
  • 核心思想: 通过比较两串答案，计算出小蓝最多能答对的题数。

4.3 算法原理

  • 统计两人答案相同的题数 a 和不同的题数 b = N - a。
  • 朋友最多答对 same = min(a, M) 题。
  • 小蓝在相同题上的答对题数也是 same。
  • 小蓝在不同题上的答对题数是 b - (M - same)。
  • 小蓝总答对数 = same + (b - M + same) = 2 * same + b - M。

4.4 代码详解

5.2 逐行解析

  • a = sum(1 for x, y in zip(s, t) if x == y): 统计两人答案相同的题数。
  • b = n - a: 计算不同的题数。
  • same = min(a, m): 朋友最多答对的题数。
  • ans = 2 * same + b - m: 计算小蓝最多能答对的题数。

5.3 优化技巧

  • 本题没有明显的空间优化或时间优化空间，代码已经是最优的。

复杂度分析

题意解析

在本题中，我们需要找到一个非空连续子数组，使得将其元素乘以 ( k ) 后，整个数组的元素和最大。原数组的总和是固定的，我们需要在原总和的基础上加上增量 (\Delta = (k-1) \times \sum_{i \in [L,R]} a_i)。因此，问题转化为在数组 ( b ) 中找到一个非空连续子数组，使得子数组的和最大。

算法思路（核心部分）

4.1 问题分析

问题的本质是寻找一个最大子段和，使得在子段中的每个元素都乘以 ( k ) 后，整个数组的和最大。我们可以通过动态规划来解决这个问题。

4.2 算法原理

  • 朴素思路: 最直观的解法是暴力枚举所有可能的子数组，然后计算其和，最后找出最大的和。这种方法的时间复杂度是 ( O(n^2) )，空间复杂度是 ( O(1) )。
  • 优化路径: 我们可以使用动态规划的思想，通过维护一个数组 ( f ) 来记录以每个元素结尾的最大子段和。状态转移方程为 ( f[i] = \max(f[i-1] + b_i, b_i) )，其中 ( b_i = a_i \times (k-1) )。

4.3 数学推导（如适用）

我们可以通过数学推导来验证动态规划的思路。假设 ( f[i] ) 表示以第 ( i ) 个元素结尾的最大子段和，则有：

其中 ( b_i = a_i \times (k-1) )。

题意解析

给定两个字符串 S 和 T，我们需要通过翻转 S 中的某些字符使得 S 变成 T。翻转的条件是字符与其左右两边都不相同，即出现 101 或 010。如果无法通过翻转得到 T，则输出 -1。

算法思路（核心部分）

4.1 问题分析

    • 首尾字符无法被翻转。

  • 朴素思路:
    • 从左到右遍历字符串，检查每个字符是否需要翻转。

    • 如果满足条件，翻转当前字符，并计数。
  • 优化路径:
    • 通过贪心算法，每次发现不匹配时立即检查并翻转。
    • 避免不必要的检查，提高效率。
  • 核心思想:
    • 翻转中间字符的前提是左右字符已经匹配。

题意解析

这个问题是一个经典的动态规划问题，通常被称为“背包问题”。给定一组物品，每种物品都有自己的重量和价值，现在有一个背包，它有一定的承重能力。目标是选择物品放入背包中，使得背包内物品的总价值最大，同时不超过背包的承重能力。

输入格式:

  • 第一行包含两个整数 ( N ) 和 ( V )，分别表示物品的数量和背包的承重能力。
  • 接下来 ( N ) 行，每行包含两个整数 ( v_i ) 和 ( w_i )，分别表示第 ( i ) 个物品的重量和价值。

输出格式:

  • 输出一个整数，表示在不超过背包承重能力的情况下，能够获得的最大价值。

算法思路（核心部分）

4.1 问题分析

  • 问题的本质是寻找在给定约束下的最大价值组合。
  • 关键观察点是每个物品的价值和重量比，以及如何利用这个比值来决定哪些物品应该被选中。

4.2 算法原理

  • 朴素思路: 对于每个物品，可以选择放入或不放入背包，从而计算出所有可能组合的最大价值。这种方法的时间复杂度为 ( O(2^N) )，在实际中不可行。
  • 优化路径: 使用动态规划，通过构建一个二维数组 ( dp )，其中 ( dp[i][j] ) 表示前 ( i ) 个物品在总重量不超过 ( j ) 的情况下可以获得的最大价值。
  • 算法选择: 动态规划是解决背包问题的标准方法，因为它避免了暴力搜索的指数级时间复杂度。
  • 核心思想: 动态规划通过存储子问题的解来避免重复计算，从而提高效率。

题意解析

给定一个整数数组，我们需要通过最少的操作次数，使得数组变成回文数组。每次操作可以将任意一个元素加一或减一。输入包括一个整数数组和一个整数k，表示最多可以进行k次操作。输出为最少操作次数。

算法思路（核心部分）

4.1 问题分析

  • 问题本质: 我们需要找到一种方法，通过最少的操作次数，使得数组的两端对称位置的元素相等。
  • 关键观察点: 数组长度、操作次数限制以及数组两端元素的初始关系。

4.2 算法原理

  • 朴素思路: 首先判断数组是否已经是回文数组，如果是，则不需要任何操作。如果不是，则从两端向中间遍历，计算需要增加或减少的次数。
  • 优化路径: 使用双指针技术，分别从数组的两端开始向中间移动，计算两端的差值，并累加到总操作次数中。
  • 算法选择: 双指针技术的时间复杂度为O(n)，空间复杂度为O(1)，非常适合本题。

4.3 数学推导（如适用）
