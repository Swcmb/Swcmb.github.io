蓝桥杯专题：帮派弟位（树形结构统计）

发表于 2024-04-08 分类于 算法竞赛 ， 蓝桥杯

题目描述

小明在游戏中参加了一个帮派，这一天他突然想知道自己在帮派中是什么地位。但是帮派的查询系统突然坏了，目前只能知道每个人的附属关系。请问你能帮帮他重建关系网并找出他的地位吗？

给定一个正整数 $n$，代表该帮派的总人数，并且小明的序号是 $m$。给出这 $n$ 个人中每个人的附属关系，确保给出的关系网为一棵树。

帮派地位的定义：按照自己手下有多少帮众决定的，注意手下的手下也算是自己的手下。如果手下的帮众相同，则按序号较小的在前面。

你能帮助小明找到自己的帮派地位吗？

输入输出格式

输入格式

第一行，两个正整数 $n(1 < n < 10^5)$ 和 $m(1 \le m \le n)$，代表该帮派的总人数以及小明的序号。
接下来 $n-1$ 行，每行两个正整数，格式如下：

  • $L, r (1 \le L, r \le n)$：代表序号为 $L$ 的人附属于序号为 $r$ 的人。

输出格式

一行，包含 1 个正整数，输出按手下人数多少排序后小明的排名。

解题思路

本题本质上是一个树形结构统计问题。

  1. 建图：根据输入的附属关系，构建一棵树。其中 $r$ 是父节点，$L$ 是子节点。
  2. 统计子树大小：题目中“手下的手下也算自己的手下”，这正好对应树结构中节点的子树大小（包含自身）。我们可以通过 DFS（深度优先搜索） 或递归的方式，自底向上计算每个节点的子树节点总数。
    • 对于叶子节点，手下人数为 0（或算上自己为 1，取决于排名定义是否包含自身。根据题目“手下”的定义，通常不包含自己，但需结合样例确认。此处代码逻辑按“手下人数”即子节点总数计算）。
  3. 排序：将所有节点按统计出的“手下人数”降序排列；若人数相同，按编号升序排列。
  4. 查询排名：遍历排序后的列表，找到小明 ($m$) 所在的位置并输出。

注意：原题数据范围 $N$ 达到 $10^5$，如果使用模拟链表合并的方式（如原文代码思路），时间复杂度可能达到 $O(N^2)$，会导致超时。推荐使用 $O(N)$ 的 DFS 算法。

修剪灌木

发表于 2024-04-08 更新于 2026-05-14 分类于 算法竞赛

问题描述

爱丽丝要完成一项修剪灌木的工作。有 $N$ 棵灌木整齐地从左到右排成一排。爱丽丝在每天傍晚会修剪一棵灌木，让这棵灌木的高度变为 $0$ 厘米。

爱丽丝修剪灌木的顺序是从最左侧的灌木开始，每天向右修剪一棵灌木。当修剪了最右侧的灌木后，她会调转方向，下一天开始向左修剪灌木。直到修剪了最左的灌木后再次调转方向，然后如此循环往复。

灌木每天从早上到傍晚会长高 $1$ 厘米，而其余时间不会长高。在第一天的早晨，所有灌木的高度都是 $0$ 厘米。

爱丽丝想知道每棵灌木最高能长到多高？

输入格式

输入一个正整数 $N$，含义如题面所述。

输出格式

输出 $N$ 行，每行一个整数，第 $i$ 行表示从左到右第 $i$ 棵灌木最高能长到多高。

样例输入

3

样例输出

2
2
2

题目分析

本题的核心在于寻找每棵灌木在被两次修剪之间的最大时间间隔。

关键逻辑推导：

  1. 生长规律：灌木每天长高 1cm，修剪后变为 0cm。因此，一棵灌木能长到的最大高度，取决于它两次被修剪之间间隔了多少天。
  2. 修剪周期：爱丽丝的修剪路径是往返的：$1 \to N \to 1 \to N \dots$。
    • 对于第 $i$ 棵灌木，它可能在爱丽丝向右走时被修剪，也可能在向左走时被修剪。
  3. 计算最大间隔：
    • 假设爱丽丝刚修剪完第 $i$ 棵灌木（位置 $i$），此时高度归零。
    • 情况一：爱丽丝继续向右走，再折返回来修剪 $i$。
      • 她需要走到最右端 $N$，再走回来。
      • 路程距离：$(N - i) + (N - i) = 2(N - i)$。
    • 情况二：爱丽丝向左走，再折返回来修剪 $i$。
      • 她需要走到最左端 $1$，再走回来。
      • 路程距离：$(i - 1) + (i - 1) = 2(i - 1)$。
  4. 结论：
    • 每棵灌木在被再次修剪前，最大生长天数取上述两种情况的较大值。
    • 由于每天生长 1cm，最大高度即为最大天数。
    • 公式：$H_i = \max(2(i-1), 2(N-i))$

复杂度分析：
该算法仅需遍历一次 $1$ 到 $N$，时间复杂度为 $O(N)$，空间复杂度为 $O(1)$，足以通过所有测试点。

问题描述

你有一架天平。现在你要设计一套砝码，使得利用这些砝码可以称出任意小于等于 $N$ 的正整数重量。那么这套砝码最少需要包含多少个砝码？注意砝码可以放在天平两边。

输入格式

输入包含一个正整数 $N$。

输出格式

输出一个整数代表答案。

题目分析与推导

这是一道经典的数学推导与贪心算法结合的题目。我们需要找到能覆盖 $[1, N]$ 范围内所有整数重量的最少砝码组合。

1. 贪心策略的选择

砝码可以放在天平的两端，这意味着对于每一个砝码，它有三种状态：

  1. 放在左盘（记为 $+w$）。
  2. 放在右盘（记为 $-w$）。
  3. 不放（记为 $0$）。

这实际上对应了平衡三进制（Balanced Ternary）的概念。

2. 为什么选择 $1, 3, 9, \dots$？

假设我们已经有一组砝码，能称出的最大重量为 $M$。当我们加入一个新的砝码 $w$ 时，由于砝码可以放在两边，我们能称出的新范围会发生变化。

设当前砝码能称出的最大重量为 $K$（即能覆盖 $[1, K]$ 的所有整数）。
当我们加入一个新砝码 $w$ 时，新的可称量范围变为：

  • 原有范围：$[1, K]$
  • 新增范围（利用新砝码 $w$）：
    • $w$ 单独：$w$
    • $w + [1, K]$：$[w+1, w+K]$
    • $w - [1, K]$（放在异侧）：$[w-K, w-1]$

  1. 第一个砝码：初始 $K=0$，则 $w_1 = 2(0) + 1 = 1$。

前 10 个幸运数字的十进制表示为：1, 2, 4, 6, 8, 40, 48, 72, 120, 126…

问题：请问第 2023 个幸运数字是多少？你只需要输出这个整数的十进制表示即可。

解题思路

本题是一道典型的枚举模拟题。由于我们需要找到第 2023 个符合条件的数，且该位置的数据规模在整型范围内，直接暴力枚举并判断即可。

具体步骤如下：

  1. 遍历整数：从 1 开始遍历所有正整数。
  2. 进制转换：对于每个整数，分别计算其在二进制、八进制、十进制、十六进制下的字符串表示。
    • Python 中可直接使用内置函数 bin(), oct(), hex()，注意它们生成的字符串带有前缀（如 0b, 0o, 0x），切片时需要去掉。
  3. 数位求和：编写一个函数，计算某个进制字符串下的各位数字之和。
    • 注意十六进制中包含 a-f，对应十进制的 10-15，需特殊处理。
  4. 整除判断：判断当前整数是否能被这四种进制下的数位和整除。
  5. 计数与输出：如果同时满足四种进制的哈沙德数条件，则计数器加 1。当计数器达到 2023 时，输出该数字并结束程序。

题目描述

在实际的开发工作中，对字符串的处理是最常见的编程任务之一。本题要求编写程序，对用户输入的字符串进行特定规则的处理。

具体处理规则如下：

  1. 首字母大写：将每个单词的首字母转换为大写。
  2. 数字字母分隔：在数字与字母之间插入下划线字符 _，以增强可读性（需同时考虑“字母在前，数字在后”和“数字在前，字母在后”两种情况）。
  3. 空格规范化：将单词间的一个或多个空格调整为 1个 空格。

输入描述

用户输入的字符串仅包含 小写字母、空格 和 数字，不含其他字符。

  • 单词间由 1 个或多个空格分隔。
  • 输入字符串长度不超过 200 个字符。

输出描述

输出经过上述规则处理后的字符串。

解题思路

本题考察字符串的基本操作，包括分割、遍历、类型判断与拼接。我们可以将问题拆解为以下三个步骤：

  1. 空格规范化：利用 Python 的 split() 方法不带参数的特性，自动将字符串按空白字符（包括多个空格、制表符等）分割成单词列表，同时去除了多余的空格。
  2. 数字字母分隔：遍历每个单词的字符。检查当前字符与下一个字符的类型，如果一个是数字一个是字母，则插入下划线。这里需要注意遍历的边界，避免索引越界。
  3. 首字母大写：在完成上述处理后，利用字符串的 upper() 方法将单词首字母大写，最后用 join() 方法将列表重新拼接成字符串。
