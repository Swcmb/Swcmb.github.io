题意解析

  • 问题描述: 给定一个字符串，求所有子串中，每个字符恰好出现一次的子串数量之和。
  • 输入格式: 输入一行字符串，长度不超过 100000。
  • 输出格式: 输出一个整数，表示所求的子串分值。

算法思路（核心部分）

4.1 问题分析

  • 本题需要计算所有子串中，每个字符恰好出现一次的子串数量之和。
  • 由于直接计算所有子串的复杂度较高，因此需要寻找一种高效的算法。

4.2 算法原理

  • 朴素思路: 枚举所有子串，统计每个字符恰好出现一次的子串数量。
  • 优化路径: 使用贡献法，计算每个字符在所有子串中的贡献。
  • 算法选择: 贡献法，通过计算每个字符在所有子串中的贡献来得到最终结果。
  • 核心思想: 对于每个字符，计算它在所有子串中恰好出现一次的子串数量，然后将所有字符的贡献相加。

4.3 数学推导

  • 贡献法的关键在于计算每个字符在所有子串中的贡献。
  • 对于位置 i 的字符 S[i]，其贡献为 (i - last[i]) * (nxt[i] - i)，其中 last[i] 表示 S[i] 上一次出现的位置，nxt[i] 表示 S[i] 下一次出现的位置。

算法思路（核心部分）

  • 朴素思路: 遍历字符串，逐个比较字符。

代码详解

核心代码段

def is_palindrome(s: str) -> bool:
n = len(s)
left, right = 0, n - 1
while left < right:
if s[left] != s[right]:
return False
left += 1
right -= 1
return True

  • def is_palindrome(s: str) -> bool: 定义函数，参数为字符串，返回值为布尔值。
  • n = len(s) 获取字符串长度。
  • left, right = 0, n - 1 初始化左右指针。
  • while left < right: 循环条件，直到左指针不小于右指针。
  • if s[left] != s[right]: 如果左右指针指向的字符不相等，则返回False。
  • left += 1 将左指针向右移动一位。
  • right -= 1 将右指针向左移动一位。
  • return True 如果所有字符都相等，则返回True。

优化技巧

  • 使用原地修改方法，避免额外的存储空间。
  • 在循环中直接比较字符，无需额外空间。

复杂度分析

  • 时间复杂度: O(n)。
  • 空间复杂度: O(1)。
  • 复杂度对比: 相比其他解法，本算法具有更低的时间和空间复杂度。
