[洛谷 P1102 A-B 数对 - 洛谷] 算法名称 + 核心优化技巧

题目概览

  • 题目来源: 洛谷
  • 题目难度: ★★★★☆
  • 标签分类: 算法标签、数据结构标签
  • 核心考点: 贪心算法、哈希表

题意解析

给定一个整数数组 nums 和一个整数 C，我们需要计算数组中所有与 C 的差值在 [0, C) 范围内的数对的数量。例如，对于数组 [1, 2, 2, 1] 和 C = 3，与 3 差值在 [0, 3) 范围内的数对有 (1, 2), (2, 1)，因此输出 2。

输入数据包括两个整数 N 和 C，以及一个长度为 N 的整数数组 nums。输出是一个整数，表示满足条件的数对数量。

算法思路（核心部分）

4.1 问题分析

问题的本质是统计数组中与给定值 C 差值在 [0, C) 范围内的数对数量。我们可以通过哈希表来记录每个数字出现的频率，然后遍历哈希表计算满足条件的数对数量。

4.2 算法原理

  • 朴素思路: 遍历数组，对于每个元素，检查其与其他元素的差值是否在 [0, C) 范围内，并累加计数。
  • 优化路径: 使用哈希表记录每个数字的频率，减少重复计算。
  • 算法选择: 哈希表方法的时间复杂度为 O(n)，空间复杂度也为 O(n)，适用于大规模数据。
  • 核心思想: 通过哈希表快速查找和统计频率，避免重复计算。

4.3 数学推导（如适用）

由于这个问题主要依赖于统计和遍历，没有复杂的数学公式推导。

4.4 多种解法对比（如适用）

解法2（排序后双指针） O(n log n) O(1) 大规模数据 中等

5.2 逐行解析

  • nums = list(map(int, input().split())): 读取长度为 N 的整数数组 nums。
  • freq = defaultdict(int): 创建一个默认值为 0 的哈希表 freq。
  • for num in nums: freq[num] += 1: 遍历数组 nums，统计每个数字的频率。
  • ans = 0: 初始化结果变量 ans。
  • for num in nums: ans += freq[num - C]: 遍历数组 nums，计算与 C 差值在 [0, C) 范围内的数对数量，并累加到 ans。
  • print(ans): 输出结果。

5.3 优化技巧

  • 空间优化: 如果只关心最终结果，可以不使用哈希表，直接遍历数组并计算差值。
  • 时间优化: 对于大规模数据，可以考虑排序后使用双指针方法，减少遍历次数。

6. 复杂度分析

题意解析

  • 问题描述: 实现一个分布式队列，支持添加元素、同步队列状态和查询最短队列长度。
  • 输入格式: 输入由操作指令组成，指令包括add、sync和query。
  • 输出格式: 对query指令，输出最短队列长度。
  • 样例分析:

    • 输出: 1

算法思路

4.1 问题分析

  • 本题的核心在于实现一个分布式队列，并确保不同节点上的队列状态一致。
  • 关键观察点包括队列的同步和状态查询。

4.2 算法原理

  • 朴素思路: 使用一个全局队列来同步所有节点的状态，每次添加元素或同步时更新全局队列。
  • 优化路径: 通过局部队列和同步操作来减少全局操作，提高效率。
  • 算法选择: 选择基于局部队列和同步操作的实现方式。
  • 核心思想: 使用局部队列存储元素，通过同步操作保持队列状态一致。

4.3 代码详解

5.1 核心代码段

  • add(element): 添加元素到节点0的队列。
  • sync(follower_id): 同步节点0的队列到指定节点。
  • query(): 查询最短队列长度。

5.2 逐行解析

  • nodes=[[] for _ in range(N)]: 初始化N个空队列。
  • add(element): 将元素添加到节点0的队列。
  • sync(follower_id): 如果指定节点的队列长度小于节点0的队列长度，则同步元素。
  • query(): 遍历所有节点，找到最短队列长度。

5.3 优化技巧

  • 使用局部队列和同步操作，减少全局操作，提高效率。

6. 复杂度分析

  • 时间复杂度: O(N)，其中N为节点数。
  • 空间复杂度: O(N)，每个节点存储一个队列。

题意解析

题目要求计算在一维直线上两组点的最小总距离。输入包括两组点的坐标，输出是最小总距离。这个问题可以通过贪心算法解决，即将两组坐标分别排序，然后按顺序一一配对，距离和最小。

算法思路

4.1 问题分析

问题的本质是将两组点在数轴上排序后，按顺序连接，使得总距离最小。关键观察点在于排序后对应项差的绝对值之和最小。

4.2 算法原理

朴素思路: 最直观的解法是计算每对点之间的距离并累加，然后找出最小的总距离。
优化路径: 通过排序和贪心算法，将问题转化为顺序匹配，减少计算量。
算法选择: 排序后贪心匹配是最优解法，时间复杂度为 (O(n \log n))，空间复杂度为 (O(n))。

4.3 数学推导

排序后，对应项差的绝对值之和最小。可以通过交换论证证明，每次交换交叉匹配，总距离不会增加。

题意解析

题目要求计算在给定的红、绿、蓝三种颜色的球中，有多少种组合方式使得某种颜色的球数量最多且不超过其他两种颜色球的数量之和。输入包括三个整数 ( r )、( g ) 和 ( b )，分别代表红、绿、蓝三种颜色的球的数量。

算法思路

4.1 问题分析

我们需要找到一个数 ( x )，使得 ( x \leq r )，( x \leq g )，并且 ( x \leq b )。同时，我们需要计算满足这些条件的组合数。

4.2 算法原理

我们可以通过二分查找来快速找到满足条件的最大 ( x )。具体步骤如下：

  1. 初始化左边界 ( left = 0 ) 和右边界 ( right = max(r, g, b) )。
  2. 在每次迭代中，计算中间值 ( mid = (left + right) // 2 )。
  3. 检查是否存在 ( x ) 使得 ( x \leq r )，( x \leq g )，并且 ( x \leq b ) 且 ( x \leq mid )。
  4. 如果存在这样的 ( x )，则更新右边界 ( right = mid )；否则更新左边界 ( left = mid + 1 )。

4.3 数学推导

通过二分查找，我们可以在 ( O(\log(\max(r, g, b))) ) 的时间复杂度内找到满足条件的最大 ( x )。
