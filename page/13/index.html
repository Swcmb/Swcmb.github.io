Manacher算法(马拉车算法)详解

发表于 2024-05-08 分类于 Algorithm

前言

在处理字符串相关问题时，最长回文子串 是一道非常经典的题目。虽然暴力求解和动态规划都能解决这个问题，但在时间复杂度上往往不尽如人意。

Manacher 算法（俗称“马拉车算法”）是一种专门用于查找字符串中最长回文子串的线性时间算法。它巧妙地利用了回文串的对称性质，将时间复杂度优化到了 $O(N)$。本文将带你深入了解这一算法的实现原理。

字符串预处理

无论是暴力解法还是 Manacher 算法，为了统一处理奇数长度和偶数长度的回文串，我们通常需要对原字符串进行预处理：在字符间插入特殊符号（如 #），并在首尾添加不同的哨兵字符（如 ^ 和 $，防止越界）。

例如，字符串 aba 处理后变为 ^#a#b#a#$，这样无论是奇数长度还是偶数长度的回文，都可以统一为中心扩展的模式。

方法一：中心扩展法

中心扩展法是一种直观的暴力解法。遍历每一个字符作为中心，向两侧扩展，直到字符不相等为止。这种方法的时间复杂度为 $O(N^2)$。

方法二：Manacher 算法

Manacher 算法在中心扩展法的基础上进行了优化。它维护了一个最右回文边界 r 和对应的中心点 c。当我们在遍历新位置 i 时，利用回文串的对称性，可以直接得出 i 关于 c 对称位置 j 的回文半径，从而避免重复计算。

核心变量说明

  • p 数组：记录以每个字符为中心的最大回文半径。
  • c：当前已知的最长回文串的中心。
  • r：当前已知的最长回文串的右边界。

算法流程

  1. 初始化 c=0, r=0。
  2. 遍历字符串，对于当前索引 i：
    • 如果 i 在右边界 r 内，利用对称性初始化 p[i] = min(r - i, p[2 * c - i])。
    • 如果 i 超出右边界，初始化 p[i] = 0。
  3. 尝试向外扩展 i 的回文半径。
  4. 如果扩展后的回文右边界超过了 r，则更新 c 和 r。

代码实现

复杂度分析

  • 时间复杂度：$O(N)$。虽然代码中包含双重循环，但由于 r 只会单调递增，且内部的扩展操作只会发生在未探测的区域，因此整体遍历次数是线性的。
  • 空间复杂度：$O(N)$。需要额外的数组 p 来存储半径信息。

总结

Manacher 算法通过利用回文串的对称性，巧妙地跳过了大量不必要的比较操作，将最长回文子串问题的解法优化到了线性时间。对于追求极致性能的字符串处理场景，它是一个非常值得掌握的算法。

算法笔记：缩位求和的迭代与递归实现

发表于 2024-03-27 更新于 2026-05-13 分类于 算法笔记

题目描述

在电子计算机普及以前，人们经常使用一种粗略的方法来验算四则运算是否正确，这种方法类似于“弃九法”。

例如： 验算 248 x 15 = 3720

  1. 对乘数和被乘数分别逐位求和，若结果为多位数则继续逐位求和，直到变为一位数。
    • 248 -> 2+4+8=14 -> 1+4=5
    • 15 -> 1+5=6
    • 乘积验算：5 x 6 = 30 -> 3+0=3
  2. 对实际运算结果逐位求和：
    • 3720 -> 3+7+2+0=12 -> 1+2=3
  3. 若两边结果一致（均为3），说明计算正确的可能性很大。

任务： 请编写一个计算机程序，对给定的数字字符串进行反复逐位求和，直到结果为一位数。

输入输出描述

输入描述：
输入为一个数字字符串，表示一个 $n$ 位数（$n < 1000$）。

输出描述：
输出一位数，表示反复逐位求和的最终结果。

算法思路

本题的核心逻辑是将数字各位相加，如果结果大于等于10，则重复该过程。这是一个典型的重复计算问题，既可以使用迭代（循环）实现，也可以使用递归实现。

代码实现

1. 迭代写法

迭代算法通过循环结构重复执行操作，直到满足终止条件。在本题中，终止条件是数字仅剩一位。

核心逻辑：

  1. 定义一个函数 num_sum 计算当前数字的各位之和。
  2. 使用 while 循环判断当前数字位数是否大于1，若大于1则调用函数更新数值。

注： 原代码中使用 int(input()) 接收输入。由于题目保证 $n<1000$，Python 支持大整数，此处转换无碍，但在处理超大数字时，直接作为字符串操作往往更优。

2. 递归写法

递归算法将问题分解为更小的子问题。对于本题，如果数字已经是一位，直接返回；否则计算各位和并调用自身。

核心逻辑：

  1. 基准条件： 如果数字长度为1，直接返回该数字。
  2. 递归步骤： 计算各位之和，将和作为参数调用自身。

方法对比

特性 迭代法 递归法
实现方式 使用循环结构 函数调用自身
代码可读性 逻辑直观，结构清晰 代码简洁，更贴近数学定义
内存消耗 通常较低，无栈帧开销 每次调用需分配栈空间，深度过大可能栈溢出
适用场景 适用于大多数线性重复任务 适用于问题可自然分解为子问题的场景

对于本题，由于输入位数 $n < 1000$，递归深度非常有限（因为数字和衰减极快，如1000位的9，第一次求和也仅为9000），因此两种方法均非常安全且高效。

蓝桥杯真题：平均 (贪心策略)

发表于 2024-03-23 更新于 2026-05-14 分类于 Algorithm

题目描述

问题描述

给定一个长度为 $n$ 的数组（$n$ 是 $10$ 的倍数），数组中的每个元素 $a_i$ 都是区间 $[0, 9]$ 中的整数。小明发现数组里每种数字出现的次数不太平均。

现在小明可以更改若干个数的值。已知更改第 $i$ 个数的代价为 $b_i$。小明希望通过更改，使得这 $10$ 种数字（$0 \sim 9$）出现的次数相等（即每种数字都出现 $n/10$ 次）。

请你计算并输出满足条件的最小代价和。

输入格式

输入的第一行包含一个正整数 $n$。
接下来 $n$ 行，第 $i$ 行包含两个整数 $a_i, b_i$，分别表示第 $i$ 个数的值和更改它的代价，用一个空格分隔。

输出格式

输出一行包含一个正整数，表示最小代价和。

样例输入

样例输出

题目分析

本题是一道典型的贪心算法应用题。

核心目标：我们需要让数字 $0 \sim 9$ 每个数字出现的次数都刚好等于 $k = n / 10$ 次。

解题思路：

  1. 数据分组：首先，我们需要统计每个数字（$0 \sim 9$）当前出现的次数以及它们对应的修改代价。我们可以创建一个列表 numbers，其中 numbers[i] 存储了所有数值为 $i$ 的修改代价列表。
  2. 贪心策略：
    • 对于某个数字 $i$，假设它当前出现的次数为 $count$，而目标次数为 $k = n/10$。
    • 如果 $count \le k$，说明该数字数量不足或刚好，不需要修改该数字，代价为 $0$。
    • 如果 $count > k$，说明该数字数量过多，我们需要将其中 $count - k$ 个数字修改为其他数字。
    • 关键点：为了使总代价最小，我们应该保留哪些数字不变？显然，我们应该保留修改代价最大的那些数字不变（因为保留它们意味着避免了最大的花费），而选择修改代价最小的那些数字将其变为其他值。
  3. 算法流程：
    • 遍历 $0 \sim 9$ 每个数字分组。
    • 对每个分组内的代价列表进行升序排序。
    • 如果该分组的大小 len(group) 大于 $k$，则计算前 len(group) - k 个代价之和（即最小的那些代价），累加到总答案中。
    • 如果分组大小小于等于 $k$，则不进行操作。

通过这种“局部最优”的选择，我们可以保证全局的总代价最小。

代码实现

复杂度分析

  • 时间复杂度：$O(n \log n)$。主要时间消耗在于排序。虽然我们对每个分组分别排序，但所有元素的总和为 $n$，平均情况下每个分组大小为 $n/10$，排序总复杂度仍在 $O(n \log n)$ 级别。
  • 空间复杂度：$O(n)$。需要存储每个数字的代价列表。

前言

在 C++ 面向对象编程（OOP）中，类是构建程序的核心基石。类不仅封装了数据，还定义了操作这些数据的方法。本文将通过一个经典的示例——封装一个求数组最大值的类 Array_max，来深入解析 C++ 类的定义、成员访问控制、成员函数实现以及对象的实例化过程。

核心知识点解析

通过上述代码，我们可以梳理出 C++ 类设计的几个关键概念：

1. 类的定义与封装

使用关键字 class 定义了 Array_max 类。类将数据（array 和 max）与操作数据的函数捆绑在一起，这就是封装。

  • Public（公有）：set_value、max_value 和 show_value 被声明为公有成员，构成了类对外部的接口。外部代码只能通过这些接口来操作对象，而无法直接访问内部数据。

2. 构造函数与对象初始化

3. 成员函数的设计

代码中的三个成员函数职责分明，符合单一职责原则：

4. 基础语法的应用

  • 循环与判断：在 set_value 和 max_value 中，使用了 for 循环遍历数组，配合 if 条件语句实现最大值的动态更新。这是 C++ 流程控制的基础应用。
  • 输入输出流：使用标准库 cin 和 cout 进行 I/O 操作，通过引入命名空间 std 简化了代码编写。

总结

这个简单的示例展示了 C++ 面向对象编程的基础流程：定义类 -> 实例化对象 -> 调用方法。掌握好访问权限的控制、成员变量的管理以及接口的设计，是进阶 C++ 高级特性的必经之路。
