[洛谷 P12842] 土地整平计划 - 洛谷

题目概览

  • 题目来源: 洛谷
  • 题目难度: ★★★★☆
  • 标签分类: 算法标签、数据结构标签
  • 核心考点: 数组操作、贪心算法、离散化

题意解析

我们有一个长度为 ( n ) 的数组 ( h )，每个位置有一个高度。每次操作可以选择一个区间 ([l, r])，将这个区间内所有位置的高度变成某个值 ( w )，代价为 ( w )。操作需要满足以下三组条件之一：

  1. 左贴边: ( l = 1,\ r < n )，且区间内所有 ( hi \neq h{r+1})，此时 ( w = h_{r+1})。
  2. 右贴边: ( l > 1,\ r = n )，且区间内所有 ( hi \neq h{l-1})，此时 ( w = h_{l-1})。
  3. 两端都不贴边: ( 1 < l \le r < n )，且 ( h{l-1} = h{r+1})，且区间内所有 ( hi \neq h{l-1})，此时 ( w = h{l-1} = h{r+1})。

每个位置至多被操作一次。目标是经过若干次操作后，所有位置高度相等，求最小总代价。

算法思路（核心部分）

4.1 问题分析

  • 问题的本质: 我们需要找到一个高度 ( X )，使得将所有高度调整为 ( X ) 的总代价最小。
  • 关键观察点:
    • 最终统一的高度 ( X ) 必定是原数组中的某个值。
    • 相邻相同高度可以压缩，减少操作次数。
  • 数据范围对算法选择的影响: 数组长度 ( n ) 最大为 ( 10^6 )，需要高效的算法来处理。

4.2 算法原理

  • 朴素思路: 遍历所有可能的高度 ( X )，计算每种高度的总代价，取最小值。
    • 时间复杂度: ( O(n^2) )
    • 空间复杂度: ( O(n) )
  • 优化路径: 使用贪心算法，先压缩连续相同的高度，再进行计算。
    • 时间复杂度: ( O(n) )
    • 空间复杂度: ( O(n) )

4.3 数学推导（如适用）

  • 通过压缩连续相同的高度，将问题转化为计算“不含 ( X ) 的极长连续段”的数量。
  • 具体推导过程如下:
    • 压缩后的数组可以看作是一些高度为 ( X ) 的“分隔点”，把数组切成了若干段全部不是 ( X ) 的连续区间。
    • 对于某个高度 ( X )，设它在压缩后数组里出现了 ( cnt_X ) 次。
    • 这些 ( X ) 把数组分成若干段:
      • 如果 ( X ) 出现在数组最左端，那么“第一段”在 ( X ) 之前为空。
      • 如果 ( X ) 出现在数组最右端，那么“最后一段”在 ( X ) 之后为空。
      • 两端之间的段，每两个相邻 ( X ) 之间正好有一段。
    • 因此，段的数量满足经典的“植树问题”关系:
      [
      \text{段数} = cnt_X + 1 - [h[1] == X] - [h[m] == X]
      ]
