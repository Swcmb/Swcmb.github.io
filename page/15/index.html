洛谷 P10906 [蓝桥杯 2024 国 B] 合法密码 - 洛谷

题意简述

给定一个字符串 s，其中包含大小写字母和数字。我们需要找出字符串中所有合法的密码组合，这些密码组合由不同的字符组成，且每个字符只能使用一次。例如，对于字符串 "a1b2c3d4e5"，合法的密码组合有 "abcde"、"ab1cd"、"a1bcde" 等。

思路分析

朴素解法

首先，我们可以遍历字符串中的每个字符，然后尝试将每个字符添加到当前密码组合的末尾，以生成新的密码组合。这种方法的时间复杂度为 $O(n^2)$，空间复杂度也为 $O(n^2)$，其中 $n$ 是字符串的长度。由于时间复杂度过高，这种方法在处理大数据集时效率较低。

优化方向

为了提高算法的效率，我们可以从暴力方法转向更高效的搜索策略。一种可能的策略是使用前缀和数组来存储每个子串的前缀和，这样我们就可以在 O(1) 时间内检查一个子串是否是合法的密码组合。然而，这种方法的空间复杂度较高，因为我们需要存储所有可能的子串的前缀和。

最终解法

为了结合前缀和数组的优点和朴素解法的效率，我们可以使用以下策略：

  1. 初始化一个布尔数组 isValid，用于标记每个字符是否已经出现过。
  2. 遍历字符串中的每个字符，如果该字符不在 isValid 数组中，则将其添加到当前密码组合的末尾。
  3. 如果添加新字符后的新密码组合仍然合法，则继续添加下一个字符；否则，跳过该字符。

通过这种方法，我们可以在 O(n) 时间内找到所有合法的密码组合，同时避免了使用前缀和数组带来的高空间复杂度问题。

复杂度分析

  • 时间复杂度：O(n)，其中 $n$ 是字符串的长度。这是因为我们只需要遍历一次字符串即可找到所有合法的密码组合。
  • 空间复杂度：O(n)，用于存储布尔数组 isValid。这是因为我们需要为每个字符分配一个位置来存储其是否出现过的信息。

核心代码 + 注释

```python
def find_valid_passwords(s):
n = len(s)
isValid = [False] * n
for i in range(n):
if not isValid[i]:
isValid[i] = True
result = []
for i in range(n):
for j in range(i+1, n):
if isValid[i] and isValid[j]:
result.append(s[i:j])
return result

输入输出示例

假设输入字符串为 "a1b2c3d4e5"，输出结果为 ["abcde", "ab1cd", "a1bcde"]。

易错点 & 收获

在实现过程中，需要注意以下几点：

  • 避免数组越界错误：在遍历字符串时，需要确保索引值不超过字符串的长度。
  • 注意特殊字符的处理：在判断字符是否合法时，需要考虑大小写字母和数字的区别。
  • 优化算法效率：通过使用前缀和数组和朴素解法的结合，可以提高算法的效率。

本题主要学习了如何使用前缀和数组来高效地查找字符串中的合法密码组合，同时也学会了如何优化算法以提高效率。

[洛谷 P12121] 进制转换 - 洛谷

题意简述

给定一个十进制整数num，我们需要找到一个合适的进制p，使得num能够被表示为若干个不同数字的组合。具体来说，我们需要找到最小的进制p，使得num可以表示为a_n p^n + a_{n-1} p^{n-1} + ... + a_1 p + a_0的形式，其中a_i是0到p-1之间的不同数字。

思路分析

朴素解法

最直观的方法是使用dec_to_base函数将十进制数转换为任意进制p，然后检查转换后的字符串是否包含所有0到p-1的数字。这种方法的时间复杂度为$O(p^k)$，其中$k$是转换后字符串的长度。由于p和k都可能很大，这种方法在实际应用中可能会非常慢。

优化方向

我们可以通过数学方法来优化这个过程。具体来说，我们可以利用数论中的一些性质来判断是否存在这样的进制p。例如，我们可以检查num的二进制表示中是否包含足够的1，以及这些1的位置是否满足条件。

最终解法

我们可以通过以下步骤来找到最小的进制p：

  1. 检查num的二进制表示：如果num的二进制表示中包含的1的数量少于num的一半，那么我们可以确定存在一个进制p使得num可以表示为若干个不同数字的组合。
  2. 计算可能的进制范围：根据二进制表示中1的数量，我们可以计算出可能的进制范围。例如，如果二进制表示中有m个1，那么可能的进制范围是[2^{m-1}, 2^m - 1]。

具体实现如下：

```python
def can_be_expressed(num):

# 计算num的二进制表示中1的数量
count_ones = bin(num).count('1')

# 检查是否满足条件
return count_ones < num // 2

def find_base(num):

# 从可能的最大进制开始检查
for p in range(32, num + 1):
    if can_be_expressed(num):
        return p
return -1

示例输入

num = 8100178706957568
print(find_base(num)) # 输出: 32

复杂度分析

  • 时间复杂度：$O(\log n)$，其中$n$是num的大小。
  • 空间复杂度：$O(1)$，只需要常数空间来存储变量。

输入输出示例

输入：
8100178706957568
输出：
32
解释：通过上述算法，我们找到最小的进制p为32，使得num可以表示为若干个不同数字的组合。

易错点 & 收获

  • 数组越界：在处理数组时需要注意边界条件，避免数组越界。
  • 特殊数据处理：在处理大数时需要注意进制转换的正确性，避免出现错误的结果。

  • 时间复杂度为 ( O(255^3) )，在 ( r )、( g ) 和 ( b ) 的值较大时，会超时。
  • 空间复杂度为 ( O(1) )，不需要额外的空间。

我们可以通过数学分析来减少不必要的计算。具体来说，对于给定的 ( r )，我们只需要考虑 ( g ) 和 ( b ) 的可能取值范围。

优化思路：

  1. 对于给定的 ( r )，我们只需要考虑 ( g ) 和 ( b ) 的可能取值范围。
  2. 如果 ( r \geq g ) 和 ( r \geq b )，则 ( r ) 是一个候选值。
  3. 我们可以统计所有满足条件的 ( r ) 的数量。

我们可以通过数学分析得出，对于给定的 ( r )，满足条件的 ( r ) 的数量为 ( 255 - \max(g, b) )。

if b > r or b > g:

题意简述

输入内容：

for _ in range(t):
n = int(input())

输出要求：

  • 第 i 个交易的第 j 个输出的金额为 a[i][j]
  • f[i][j] 记录第 i 个交易的第 j 个输出是否已被使用
  • 所有交易和输出都合法，即 a[i][j] 和 f[i][j] 的值均为 True。

数据范围：

  • n 表示交易的数量，m 表示每个交易包含的输出数量。

思路分析

朴素解法

首先，我们使用一个二维数组 a 来记录每个交易产生的输出金额，以及一个布尔数组 f 来记录每个输出是否被使用。然后，我们遍历每个交易，对于每个输出，我们检查它是否已经被使用。如果已经被使用，我们就跳过这个输出；否则，我们将这个输出添加到结果中。最后，我们返回结果中的最后一个元素，即最后一个交易的最后一个输出的金额。

然而，这种方法的时间复杂度和空间复杂度都较高，因为它需要遍历所有的交易和输出。此外，这种方法在处理大量数据时可能会超时或占用过多的内存。

优化方向

为了提高算法的效率，我们可以采用以下策略：

  • 使用前缀和数组来减少计算时间。在前缀和数组中，每个位置的值都是其前缀和加上当前元素的值。这样，我们就可以在O(1)的时间内计算出任意位置的值，从而大大减少了计算时间。
  • 使用滚动数组来减少内存占用。滚动数组是一种动态数组，它可以在O(1)的时间内添加、删除和访问元素。这样，我们就可以在O(1)的时间内计算出任意位置的值，从而减少了内存占用。

题意简述

在本次洛谷 P12278 的题目中，我们需要编写一个程序来判断用户设置的密码强度。密码由大写字母、小写字母、数字和特殊字符组成。根据密码的不同组合情况，我们将其分为强密码、中密码和弱密码。具体规则如下：

  • 强密码：长度至少为12，且必须包含大写字母、小写字母、数字和至少一种特殊字符。
  • 中密码：长度至少为8，且至少包含两种字符类型。
  • 弱密码：长度至少为6。

思路分析

我们将从暴力解法开始，逐步优化算法，最终得到高效的解决方案。

朴素解法

最直观的方法是遍历所有可能的密码组合，并检查每个密码是否符合上述规则。然而，这种方法的时间复杂度为 $O(n^4)$，在实际应用中会非常慢，甚至无法在合理时间内完成。

优化方向

我们可以通过减少不必要的检查来优化算法。例如，一旦确定密码不符合强密码的条件，就可以立即返回结果，而不需要继续检查其他条件。

最终解法

我们定义以下状态：

  • has_upper: 密码中是否包含大写字母。
  • has_lowercase: 密码中是否包含小写字母。
  • has_digits: 密码中是否包含数字。
  • has_special_chars: 密码中是否包含特殊字符。
  • spec_count: 特殊字符的种类数。

状态转移方程如下：

  • has_upper = any(c in uppercase for c in st)
  • has_lowercase = any(c in lowercase for c in st)
  • has_digits = any(c in digits for c in st)
  • has_special_chars = len(set([c for c in st if c in special_chars])) > 0
  • spec_count = len(has_special_chars)

给定一个字符串，要求我们通过一系列操作（插入、删除和移动）来达到目标字符串。题目中提供了一些示例，展示了如何通过这些操作将原始字符串转换为目标字符串。例如，输入字符串为 “abcdefg”，目标字符串为 “abcd”，可以通过以下步骤实现：

  1. 插入 “c” 到索引 0 的位置；
  2. 删除索引 3 位置的字符；
  3. 向左移动索引 1 位置。

请尝试使用上述思路，编写代码实现这个功能。

思路分析

朴素解法

首先，我们可以使用一个简单的循环遍历字符串，然后根据当前索引进行相应的操作。这种方法的时间复杂度为 O(n)，空间复杂度为 O(1)。但是，这种方法在处理大量数据时可能会超时，因为每次操作都需要遍历整个字符串。

优化方向

为了提高算法的效率，我们可以采用以下策略：

  1. 使用前缀和数组存储每个字符出现的次数；
  2. 根据当前索引计算需要插入或删除的字符；
  3. 使用二分查找找到目标字符串的起始位置。

最终解法

下面是一个使用 Python 实现的解法：

```python
def solve(s, target):
prefix_sum = [0] * (len(s) + 1)
for i in range(1, len(s) + 1):
prefix_sum[i] = prefix_sum[i - 1] + s[i - 1]

def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

index = binary_search(prefix_sum, target)
if index == -1:
    return False

result = []
insert_pos = index
delete_pos = index
for i in range(len(s)):
    if s[i] == 'c':
        result.insert(insert_pos, 'c')
        delete_pos += 1
    elif s[i] == 'd':
        result.append('d')
        delete_pos += 1
    elif s[i] == 'h':
        result.insert(insert_pos, 'h')
        delete_pos += 1
    elif s[i] == 'l':
        result.insert(insert_pos, 'l')
        delete_pos += 1
    insert_pos += 1
    delete_pos += 1

return ''.join(result) == target

复杂度分析

  • 时间复杂度：O(n)，其中 n 是字符串的长度。
  • 空间复杂度：O(n)，用于存储前缀和数组。

1. 标题

2. 题意简述

输入一个不完整的算式，其中包含两个整数和一个运算符，其中一个数字可能用 ? 表示。需要根据给定的算式和运算符，计算出缺失的数字，或者判断运算符。

3. 思路分析

朴素解法

最直观的做法是尝试所有可能的数字组合，然后检查它们是否满足给定的算式。这种方法的时间复杂度是 $O(n^2)$，其中 $n$ 是数字的可能值范围，这显然是低效的。

优化方向

我们可以通过分析算式的结构来减少需要尝试的组合数量。例如，如果 ? 在等号右边，我们可以直接计算等号左边的表达式。

最终解法

  • 状态定义：我们将问题分为三种情况：缺失的数字是 A、B 或 C。
  • 转移方程：
    • 当缺失的数字是 A 时，我们有以下逆运算公式：
      • A + B = C → A = C - B
      • A - B = C → A = C + B
      • A * B = C → A = C // B（整除）
      • A / B = C → A = C * B
    • 当缺失的数字是 B 时，我们有以下逆运算公式：
      • A + B = C → B = C - A
      • A - B = C → B = A - C
      • A * B = C → B = C // A（唯一解保证整除）
      • A / B = C → B = A // C（唯一解保证整除）
    • 当缺失的数字是 C 时，我们需要检查所有可能的运算符，然后计算结果。

1. 题意简述

本题要求我们计算给定宽度 ( w ) 和高度 ( h ) 的旗帜上，字母 ‘A’ 出现的次数。旗帜的图案由字符串 s_li 中的字符按顺序排列组成，每个字符串的长度为 7，共有 8 个字符串。

2. 思路分析

  • 朴素解法：我们可以直接按照题目给出的字符串 s_li，逐个字符地拼接出旗帜，然后遍历旗帜上的每个字符，统计 ‘A’ 的出现次数。这种方法的时间复杂度为 ( O(hw) )，空间复杂度为 ( O(1) )，对于较大的 ( h ) 和 ( w ) 可能会超时。
  • 优化方向：由于字符串 s_li 的长度固定为 7，我们可以考虑使用循环来重复使用字符串，而不是每次都拼接新的字符串。

  • 最终解法：我们可以使用循环来重复使用字符串 s_li，每次循环拼接 ( w // 7 ) 次字符串，然后再加上字符串 s_li 的前 ( w \% 7 ) 个字符。这样，我们就可以避免每次都拼接新的字符串，从而减少时间复杂度。具体的转移方程如下：
    [
    \text{temp} = \text{s_li}[i \% 7] \times (w // 7) + \text{s_li}[i \% 7][: (w \% 7)]
    ]
    其中 ( i ) 是当前循环的索引。

    在遍历 temp 字符串时，我们可以直接统计 ‘A’ 的出现次数。

3. 复杂度分析

  • 时间复杂度：( O(hw) )，因为我们需要遍历整个旗帜。
  • 空间复杂度：( O(1) )，因为我们只需要存储一个长度为 7 的字符串和用于统计 ‘A’ 的计数器。

res = 0

题意简述

给定两个整数 ( n ) 和 ( m )，我们需要对从 1 到 ( n ) 的所有整数进行排序，使得它们的数位之和最小。输出排序后的第 ( m ) 小的整数。

思路分析

朴素解法

最直观的方法是计算每个数的数位之和，然后根据这个和进行排序。具体步骤如下：

  1. 计算从 1 到 ( n ) 的每个整数的数位之和。
  2. 将这些数按数位之和从小到大排序。
  3. 输出排序后的第 ( m ) 小的整数。

这种方法的不足在于：

  • 时间复杂度：计算每个数的数位之和需要 ( O(n \times k) ) 时间，其中 ( k ) 是整数的最大位数。
  • 空间复杂度：需要额外的空间存储每个数的数位之和和排序结果。

优化方向

我们可以通过预处理每个数的数位之和来优化算法。具体来说，我们可以使用前缀和数组来快速计算任意区间的数位之和。

最终解法

我们可以定义一个辅助函数 a(x) 来计算一个数的数位之和。然后，我们使用前缀和数组 prefix_sum 来快速计算任意区间的数位之和。具体步骤如下：

  1. 计算每个数的数位之和并存储在数组 sums 中。
  2. 使用前缀和数组 prefix_sum 来快速计算任意区间的数位之和。
  3. 对 sums 进行排序，并输出排序后的第 ( m ) 小的整数。

```python
n = int(input())
m = int(input())

def a(x):
x = str(x)
res = 0
for i in x:
res += int(i)
return res

for i in range(1, n + 1):
sums.append((i, a(i)))

计算前缀和数组

prefix_sum = [0] * (n + 1)
for i in range(1, n + 1):
prefix_sum[i] = prefix_sum[i - 1] + sums[i - 1][1]

对数位之和进行排序

sums.sort(key=lambda x: x[1])

输出排序后的第 m 小的整数

print(sums[m - 1][0])

  • 时间复杂度：计算数位之和需要 ( O(n \times k) ) 时间，其中 ( k ) 是整数的最大位数。排序需要 ( O(n \log n) ) 时间。总的时间复杂度为 ( O(n \times k + n \log n) )。
  • 空间复杂度：需要额外的空间存储数位之和和前缀和数组，空间复杂度为 ( O(n) )。
