[洛谷 P13893] 工作时长 - 洛谷

题意简述

在洛谷平台上，题目P13893要求我们计算某人的工作时间。具体来说，我们需要读取一系列的时间点，每个时间点代表一个工作时段的开始或结束，然后计算出总的工作时长。

思路分析

朴素解法

最直观的方法是遍历所有时间点，对于每一对相邻的时间点，计算它们之间的差值并累加。然而，这种方法的时间复杂度为$O(n^2)$，在数据量较大时会导致超时。

优化方向

我们可以通过排序和双指针技术来优化算法。首先，对时间点进行排序，然后使用两个指针分别指向每对相邻的时间点，计算它们之间的差值并累加。这样，我们只需要遍历一次时间点列表，时间复杂度降低到$O(n \log n)$。

最终解法

我们定义两个指针i和j，分别指向当前考虑的开始和结束时间点。对于每一对相邻的时间点dt[i]和dt[j]，我们计算它们之间的差值并累加到总时长中。然后，我们将j指针向前移动一位，继续考虑下一对时间点。当i和j相遇时，所有时间点都已考虑完毕。

```python
from datetime import datetime

with open(“1.in”,”r”) as f:
l = f.readlines()
dt = sorted([datetime.fromisoformat(i.strip() for i in l)])
secs = 0
for i in range(0, len(dt) - 1, 2):
secs += (dt[i + 1] - dt[i]).seconds
print(secs)

复杂度分析

  • 时间复杂度：$O(n \log n)$，主要由排序步骤决定。
  • 空间复杂度：$O(n)$，用于存储时间点列表。

[洛谷 P8680] 特别数的和 - 洛谷

题意简述

本题是关于计算从1到n之间所有特别数的和。特别数是指各位数字之和为完全平方数的数。例如，121是一个特别数，因为1+2+1=4，而4是一个完全平方数。

思路分析

朴素解法

最直观的方法是遍历从1到n的所有整数，检查每个整数的各位数字之和是否为完全平方数。如果是，则将其加到结果中。然而，这种方法的时间复杂度为$O(n \times k)$，其中$k$是数字的最大位数，对于较大的$n$，这种方法会非常慢。

优化方向

我们可以通过预先计算所有可能的完全平方数来优化这个过程。具体来说，我们可以生成所有小于等于9999（因为最大的三位数各位数字之和为9+9+9=27）的完全平方数，并存储在一个集合中。然后，在遍历从1到n的整数时，检查其各位数字之和是否在集合中。

最终解法

我们定义一个辅助函数a(num)，用于判断一个数是否为特别数。然后，我们遍历从1到n的所有整数，使用a(num)函数检查其是否为特别数，并累加到结果中。

```python
def a(num):
s = str(num)
return any(int(digit) ** 2 == sum(map(int, s)) for digit in s)

n = int(input())
res = 0
for i in range(1, n + 1):
if a(i):
res += i
print(res)

复杂度分析

  • 时间复杂度：预处理完全平方数的时间复杂度为$O(1)$，遍历从1到n的时间复杂度为$O(n)$，因此总的时间复杂度为$O(n)$。
  • 空间复杂度：我们使用了一个集合来存储完全平方数，空间复杂度为$O(1)$。

输入输出示例

输入：
100
输出：
40
解释：
在1到100之间的特别数有：1, 4, 9, 16, 25, 36, 49, 64, 81。它们的和为40。

易错点 & 收获

  • 边界条件：确保输入的n是一个正整数。
  • 特殊情况处理：对于非常大的n，虽然时间复杂度是线性的，但实际运行时间仍然可能很长。可以通过优化算法进一步减少运行时间。

优化方向

为了提高算法的效率，我们可以从以下几个方面进行优化：

  1. 减少不必要的计算：在计算中间值时，我们可以直接使用前n-i个数组元素的和，而不需要再计算一次。这样可以减少一半的计算量。

  2. 利用前缀和的性质：在前缀和的定义中，我们知道前n-i个数组元素的和等于第i+1个数组元素与前n-i-1个数组元素的和之差。因此，我们可以将这个问题转化为求解两个子问题：一个是求第i+1个数组元素与前n-i-1个数组元素的和，另一个是求第i+1个数组元素与前n-i个数组元素的和。这样，我们就可以将问题的规模缩小到原来的一半。

市面上的 C 语言教程，往往存在一个严重的逻辑缺陷：无脑陈列细节，缺乏主线逻辑。

这种风气甚至可以追溯到 C 语言之父 Dennis Ritchie 的经典著作《C程序设计语言》。严格来说，这本书是一本“C 语言特性手册”，面向的是“初学 C 语言的程序员”，而非“编程零基础初学者”。然而，后世的许多教材（包括《C Primer Plus》等）都沿用了这种“字典式”的编排顺序，导致初学者在 Hello World 阶段就迷失了方向。

程序即机器

一个优秀的程序设计，就像设计一台复杂的机器。它不是一块铁板，而是由多个功能模块组合而成。这些模块各司其职，最终由一个主体程序（通常是 main）统一调度。

让我们以编写一个“C 语言玩具车”程序为例，看看模块化思维是如何运作的。

1.0 版：单文件原型

在最原始的阶段，我们将所有功能模块写在一个文件中。这虽然简单，但已经体现了“模块化”的雏形——main 函数作为指挥官，负责调度各个功能函数。

数据结构学习笔记：图论之七桥问题与欧拉回路（C++实现）

发表于 2024-10-30 更新于 2026-05-14 分类于 计算机科学 ， 数据结构

一、背景引入：哥尼斯堡七桥问题

七桥问题是图论发展史上的经典案例，由著名数学家欧拉在18世纪提出。问题的背景源于普鲁士的哥尼斯堡（现俄罗斯加里宁格勒），普雷格尔河穿过该城，形成了四个区域（两个岛屿及两岸），这四个区域由七座桥连接。

问题核心：是否可以从某个区域出发，经过所有七座桥，且每座桥只经过一次，最后回到起点？

问题的图论模型

为了解决这一问题，我们可以将实际问题抽象为数学模型：

  1. 顶点：将四个区域抽象为图中的四个顶点。
  2. 边：将七座桥抽象为连接顶点的边。

根据图论中的判定规则，欧拉回路存在的条件如下：

  • 欧拉回路：通过图中每一条边且仅通过一次，最后回到起点的回路。存在的充要条件是图中所有顶点的度数均为偶数。
  • 欧拉路径：通过图中每一条边且仅通过一次，但不要求回到起点的路径。存在的条件是图中恰好有两个顶点的度数为奇数（起点和终点）。
  • 如果奇度数顶点的数量超过两个，则既不存在欧拉回路，也不存在欧拉路径。

七桥问题的求解

在七桥问题中，四个区域（顶点）连接桥梁的情况如下：

  • 两个区域各自连接了3座桥（度数为奇数）。
  • 另外两个区域各自连接了3座桥（度数为奇数）。（注：历史真实数据为四个区域度数均为奇数，或根据具体抽象方式不同而变化，但奇度数顶点数量必然超过2个）。

结论：由于奇度数顶点的数量超过两个（实际上四个顶点的度数均为奇数），因此不存在欧拉回路，也不存在欧拉路径。

二、C++ 代码实现

下面通过 C++ 程序来实现上述判定逻辑。我们定义一个 EulerCircuit 类，通过邻接矩阵存储图结构，并计算奇度数顶点的数量来进行判定。

代码实现

```cpp

include

using namespace std;

// 定义图的最大顶点数
const int MaxSize = 4;

class EulerCircuit {
public:
// 构造函数，初始化图
EulerCircuit(int a[][MaxSize], int n);

// 计算奇度数顶点的数量
int oddVertexNum();

private:
int mat[MaxSize][MaxSize]; // 邻接矩阵
int vertexNum; // 顶点数量
};

// 构造函数实现
EulerCircuit::EulerCircuit(int a[][MaxSize], int n) {
for (int i = 0; i < n; i++) {
for (int j = 0; j < n; j++) {
mat[i][j] = a[i][j];
}
}
vertexNum = n;
}

// 计算奇度数顶点数量的函数实现
int EulerCircuit::oddVertexNum() {
int count = 0;
int degree;

for (int i = 0; i < vertexNum; i++) {
    degree = 0;
    // 计算第i个顶点的度数（邻接矩阵第i行元素之和）
    for (int j = 0; j < vertexNum; j++) {
        degree = degree + mat[i][j];
    }

    // 判断度数是否为奇数
    if (degree % 2 != 0) {
        count++;
    }
}
return count;

}

int main() {
// 定义邻接矩阵表示的图
// 这里的矩阵对应文中描述的连接情况或具体的测试用例
int a[4][MaxSize] = {
{0, 1, 2, 2}, // 顶点0：连接顶点1(1座), 顶点2(2座), 顶点3(2座) -> 度数5 (奇数)
{1, 0, 1, 1}, // 顶点1：连接顶点0(1座), 顶点2(1座), 顶点3(1座) -> 度数3 (奇数)
{2, 1, 0, 0}, // 顶点2：连接顶点0(2座), 顶点1(1座) -> 度数3 (奇数)
{2, 1, 0, 0} // 顶点3：连接顶点0(2座), 顶点1(1座) -> 度数3 (奇数)
};

// 实例化对象
EulerCircuit G{a, 4};

// 获取奇度数顶点数量
int num = G.oddVertexNum();

// 输出判定结果
if (num >= 2) {
    // 注意：若num==2，存在欧拉路径；若num>2，不存在任何路径。
    // 此处代码逻辑简化了判定，实际应用中可细分。
    cout << num << "个地方通奇数桥，不存在欧拉回路" << endl;
} else {
    cout << "存在欧拉回路" << endl;
}

return 0;

}

代码解析

  1. 数据结构：使用二维数组 mat[MaxSize][MaxSize] 作为邻接矩阵存储图。mat[i][j] 的值表示顶点 $i$ 和顶点 $j$ 之间的边数（桥的数量）。
  2. 度数计算：在 oddVertexNum 函数中，通过双层循环计算每个顶点的度数。对于无向图，顶点 $i$ 的度数即为邻接矩阵第 $i$ 行所有元素之和。
  3. 判定逻辑：主函数中定义了一个具体的邻接矩阵。计算结果显示有4个奇度数顶点，根据欧拉回路判定定理，程序正确输出了“不存在欧拉回路”的结论。

七桥问题不仅是图论的起源，也为我们提供了解决“一笔画”问题的数学模型。通过将实际问题抽象化，并利用编程手段计算顶点度数，我们可以轻松判断一个图是否存在欧拉回路。这体现了数据结构与算法在解决实际问题中的强大威力。
