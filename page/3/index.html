  • 优化路径: 使用动态规划数组 dp，状态转移方程 dp[i] = max(dp[j] + 1) for j in range(i)。
  • 算法选择: 动态规划效率高，适用于小规模数据。
  • 核心思想: 动态规划通过存储中间结果避免重复计算。

  • 复杂度分析：时间复杂度 O(n^2)，空间复杂度 O(n)。

[洛谷 P1001] 操作数组 + 核心优化技巧

题意解析

给定一个整数 n，我们需要实现两个函数 opsA 和 opsB。opsA 函数将数组中索引为 idx 的元素加一，然后对 10 取模；opsB 函数将数组中索引为 idx 的元素减一，然后对 10 取模。函数应该返回修改后的数组。

算法思路（核心部分）

4.1 问题分析

  • 问题的本质是数组元素的循环增减操作。
  • 关键观察点是索引 idx 和数组长度 n。
  • 数据范围对算法选择的影响较小，因为操作是对单个数字进行的。

4.2 算法原理

  • 朴素思路: 直接对数组进行操作，遍历数组并修改指定索引的元素。
  • 优化路径: 由于操作是对单个数字进行的，且不需要频繁修改数组，直接遍历即可。
  • 算法选择: 直接遍历数组，时间复杂度为 O(n)，空间复杂度为 O(1)。

4.3 数学推导（如适用）

  • 无需复杂的数学推导，只需进行基本的算术运算。

4.4 多种解法对比（如适用）

解法 时间复杂度 空间复杂度 适用场景 代码难度
直接遍历 O(n) O(1) 小规模数据 简单

代码详解

5.1 核心代码段

5.2 逐行解析

  • n = 123456: 初始化一个整数 n。
  • def opsA(idx):: 定义函数 opsA，接受一个索引 idx。
  • temp = list(str(n)): 将整数 n 转换为字符串列表 temp。
  • temp[idx] = str((int(temp[idx]) + 1) % 10): 将 temp 列表中索引为 idx 的元素加一并对 10 取模，然后将结果转换为字符串并赋值回 temp 列表。
  • return int("".join(temp)): 将修改后的 temp 列表转换回整数并返回。
  • def opsB(idx):: 定义函数 opsB，接受一个索引 idx。
  • temp = list(str(n)): 将整数 n 转换为字符串列表 temp。
  • temp[idx] = str((int(temp[idx]) - 1) % 10): 将 temp 列表中索引为 idx 的元素减一并对 10 取模，然后将结果转换为字符串并赋值回 temp 列表。
  • return int("".join(temp)): 将修改后的 temp 列表转换回整数并返回。

5.3 优化技巧

  • 空间优化: 由于我们只使用了常数个额外变量，空间复杂度为 O(1)。
  • 时间优化: 直接遍历数组，时间复杂度为 O(n)，无需进一步优化。

复杂度分析

  • 时间复杂度: O(n)，因为我们只需要遍历一次数组。
  • 空间复杂度: O(1)，因为我们只使用了常数个额外变量。

输入输出示例

  • 样例输入: n = 123456, idx = 2
  • 样例输出: opsA(2) 返回 234567, opsB(2) 返回 123456

    1. 调用 opsA(2)，将 n 转换为字符串列表 ['1', '2', '3', '4', '5', '6']，修改索引为 2 的元素为 ‘3’，得到列表 ['1', '2', '3', '4', '5', '6']，转换为整数 123456。
    2. 调用 opsB(2)，将 n 转换为字符串列表 ['1', '2', '3', '4', '5', '6']，修改索引为 2 的元素为 ‘2’，得到列表 ['1', '2', '2', '4', '5', '6']，转换为整数 123456。

常见错误与调试技巧

  • 易错点:
    1. 索引越界：确保 idx 在数组范围内。
    2. 类型转换错误：确保所有操作都在整数范围内进行。
  • 调试方法:
    1. 打印中间结果，检查每一步的操作是否正确。

5.2 逐行解析

  • dfs(pos, start): 定义深度优先搜索函数，pos 是当前组合的长度，start 是下一个元素的下界。
  • if pos == m: 如果当前组合长度等于 m，则输出该组合。
  • for i in range(start, (n - (m - pos) + 1) + 1): 遍历可能的元素。
  • current.append(i): 将当前元素添加到组合中。
  • dfs(pos + 1, i + 1): 递归调用 dfs，尝试添加下一个元素。
  • current.pop(): 回溯，移除最后一个元素。

5.3 优化技巧

  • 使用回溯算法避免了不必要的枚举，提高了效率。

6. 复杂度分析

  • 时间复杂度: O(C(n, m))，其中 C(n, m) 是从 n 个不同元素中取 m 个元素的组合数。
  • 空间复杂度: O(m)，用于存储当前组合。

7. 输入输出示例

  • 样例输入: 5 3
  • 样例输出: 1 2 0 1 1 2 2 3

8. 常见错误与调试技巧

  • 易错点: 忘记回溯，导致输出重复的组合。
  • 调试方法: 使用小规模数据测试代码，逐步增加数据规模，观察输出是否正确。
