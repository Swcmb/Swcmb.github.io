重点步骤解析

1. 参数编码

在 GET 请求中，参数通常直接拼接在 URL 后面。但在 POST 请求中，参数被放置在请求体中。

关键点：

  • urllib.parse.urlencode(data)：将字典格式的数据转换为 URL 编码格式的字符串（如 kw=hello）。
  • .encode('utf-8')：urllib 的 Request 对象接受的 data 参数必须是 bytes（字节流） 类型，因此必须调用 encode 方法将字符串转换为字节流。

2. 请求对象定制

使用 urllib.request.Request 类可以更灵活地定制请求。

  • url：目标地址。
  • data：POST 请求体数据。如果不传或为 None，则为 GET 请求；传入 bytes 类型数据，则为 POST 请求。
  • headers：请求头，用于反爬虫伪装（此处添加了 User-Agent）。

3. JSON 数据解析

服务器返回的数据通常是 JSON 格式的字符串。虽然字符串可以直接阅读，但在程序处理中，我们更倾向于将其转换为 Python 的字典或列表，以便通过键值对获取数据。

常见问题与注意点

  1. 参数类型：务必确保传入 Request 的 data 参数已经经过 urlencode 处理并转换为 bytes 类型。
  2. 字符编码：服务器返回的数据可能有不同的编码格式，通常为 utf-8。使用 response.read().decode('utf-8') 进行解码。
  3. 异常处理：在网络请求中，建议使用 try-except 捕获 URLError 或 HTTPError，以防止程序因网络问题崩溃。

总结

相比 GET 请求，使用 urllib 发送 POST 请求主要多了一步参数编码转字节流的过程。掌握 urlencode、encode 以及 json.loads 这三个方法，就能应对大多数基础的 POST 请求爬虫场景。
