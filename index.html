  • 题目来源: 洛谷
  • 题目难度: ★★★★☆
  • 标签分类: 动态规划, 前缀和
  • 核心考点: 动态规划的状态转移方程

题意解析

这个问题是一个典型的动态规划问题，要求计算在给定范围内满足特定条件的数的数量。具体来说，我们需要计算在1到27之间，有多少个数可以被3整除，多少个数可以被4整除，以及这些数中有多少个同时被3和4整除。

算法思路（核心部分）

4.1 问题分析

  • 状态定义: 设 ( dp[i][j][k] ) 表示前 ( i ) 个数中，有 ( j ) 个数能被3整除，且其中有 ( k ) 个数同时被3和4整除。
  • 状态转移方程:
    • 如果当前数 ( n ) 能被3整除但不能被4整除，则 ( dp[i][j][k] = dp[i-1][j][0] )。
    • 如果当前数 ( n ) 能被4整除但不能被3整除，则 ( dp[i][j][k] = dp[i-1][j-1][0] )。
    • 如果当前数 ( n ) 同时被3和4整除，则 ( dp[i][j][k] = dp[i-1][j-1][1] )。
  • 初始化: ( dp[0][0][0] = 1 )，其他为0。
  • 结果: 最终结果是 ( dp[n][j][k] ) 的总和。

4.2 算法原理

  • 朴素思路: 直接使用动态规划的状态转移方程进行计算。
  • 优化路径: 可以通过前缀和优化减少重复计算。
  • 算法选择: 动态规划是解决这类问题的最佳选择，因为它可以有效地利用子问题的解来构建原问题的解。
  • 核心思想: 通过定义状态和状态转移方程，逐步构建出最终的结果。

核心优化技巧

在解决这类问题时，我们通常需要遍历所有可能的组合，并检查它们是否满足条件。为了提高效率，我们可以采用以下策略：

  1. 剪枝：在遍历过程中，如果某个组合已经满足条件，那么我们就可以直接返回结果，而不需要继续检查其他组合。
  2. 动态规划：如果我们已经找到了一个解，那么这个解就可以作为子问题的解，从而避免重复计算。

解题思路

问题分析

  • 问题描述：给定一个整数数组 nums 和一个目标值 target，我们需要从数组中选择若干个数字，使得它们的和等于 target。
  • 输入格式：整数数组 nums 的长度为 n，目标值 target 是一个整数。
  • 输出格式：一个整数数组，表示选择的数字。

算法原理

  • 朴素思路：遍历数组，对于每个元素，尝试将其添加到当前和中，直到和等于 target 或者遍历完所有元素。
  • 优化路径：使用动态规划的思想，将之前计算过的结果存储起来，避免重复计算。
  • 核心思想：通过剪枝和动态规划，减少不必要的计算，提高算法的效率。

数学推导

假设我们已经计算出了前 i 个元素的和为 sum_i，那么第 i+1 个元素的和为 target - sum_i。因此，我们只需要检查是否存在一个索引 j，使得 nums[j] + sum_i == target - sum_i。
