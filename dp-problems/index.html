动态规划-闫氏DP分析法

核心思想

所有DP问题的本质都是 有限集合中的最优化问题（求max/min/count/存在性）。因为集合元素通常是指数级别（(2^N), (N!)），暴力枚举会超时，DP通过每次处理一类方案而非一个方案来优化。

闫氏DP分析法通过两个阶段完成分析：

阶段 名称 做了什么
第一阶段 状态表示（化零为整） 把有相似点的方案归为一个子集，用一个状态 (f[\ldots]) 表示
第二阶段 状态计算（化整为零） 把 (f[\ldots]) 对应的集合划分为若干子集，分别求值后合并

分析流程（每道DP题必须严格按此步骤）

第一步：确认问题本质

先确认这道题是不是 “有限集合中求最值/数量” 的问题：

  • 方案总数是否有限？（物品数、字符串长度、数组大小等是否给定上限）
  • 目标是不是求 max / min / count / 是否存在？
  • 如果是，就可以用 DP，继续下一步。

第二步：状态表示（化零为整）—— 定义 (f[\ldots])

从两个角度分析每个状态：

角度1：集合是什么？（最关键，后续所有分析以此为准绳）

用这个格式描述：

(f[i][j][…]) 表示 所有满足以下条件的方案的集合：

  1. 条件1（通常对应第一维，如”只考虑前 i 个物品”）
  2. 条件2（通常对应第二维，如”总体积不超过 j”）
  3. …

规则：每个维度对应一个限制条件。常见的维度有：

  • 考虑前 i 个元素
  • 体积/重量不超过 j
  • 恰好选 k 个
  • 以第 i 个字符结尾
  • …

用到的状态维度数量取决于有几个独立的限制条件。

角度2：属性是什么？（看题目问什么）

题目问什么 属性 合并方式
最大值 max 各子集取 max
最小值 min 各子集取 min
方案数 count 各子集求和
是否存在 bool 各子集取 or

最终答案是什么？把题目要求的参数代入状态定义即可得到。例如 01 背包的答案是 (f[N][V])。

第三步：状态计算（化整为零）—— 推导转移方程

3.1 找最后一个不同点

这是划分集合的依据。问自己：在当前状态表示下，不同的方案在 最后一步 有什么区别？

常见模式：

  • 选择类（背包）：第 i 个物品选或不选 / 选几个
  • 区间类：最后一次合并的分界点 k（左边是哪一段，右边是哪一段）
  • 序列类：最后一个字符是否包含 / 以哪个字符结尾
  • 状态机类：最后一步处于哪个状态

3.2 划分子集

以最后一个不同点为依据，把 (f[\ldots]) 的集合划分为若干互不相交的子集。

3.3 分别求每个子集的值

对于每个子集，从定义出发推导它的值：

  • 先看这个子集中的方案有什么共同特征（不变部分）
  • 再看变化部分对应哪个更小的状态（已定义过的 (f)）
  • 将不变部分的值加上变化部分的值

3.4 合并得出转移方程

根据属性类型合并：

  • max 属性 → (f[…] = \max(子集1的值, 子集2的值, \ldots))
  • min 属性 → (f[…] = \min(子集1的值, 子集2的值, \ldots))
  • count 属性 → (f[…] = 子集1的值 + 子集2的值 + \ldots)

3.5 关于”不重复”原则

属性类型 是否需要不重复 原因
count（数量） 必须 重复会导致多算
max / min 不一定 重复不影响最值结果
bool（是否存在） 不一定 有就是有

当无法恰好做到”不重不漏”地划分时（如 LCS 问题），如果是求 max/min，可以放宽”不重复”的要求，只需要保证不遗漏即可——用更大的集合去覆盖目标子集，允许重叠。

第四步：确定边界条件和初始化

根据集合定义确定：

  • 哪些状态是平凡情况（如 (f[0][] = 0)，(f[][0] = 0)）
  • 哪些状态不存在（设为 -INF / INF）
  • 全局变量默认值是否能覆盖边界（如 C++ 全局数组默认为 0）

一切以第二步中定义的”集合是什么”为准绳。

第五步：确定循环顺序

循环顺序取决于状态之间的依赖关系：计算 (f[i][j]) 时，它依赖的所有状态必须已经被计算过。

常见惯例：

  • 二维状态：外层 i 从 1 到 N，内层 j 从 0 到 V（无特殊限制）
  • 区间 DP：外层枚举区间长度 len（从小到大），内层枚举左端点 i
  • 树形 DP：DFS 后序遍历

第六步：写出朴素代码

先写二维/多维的完整版本，确保逻辑正确。不要跳过这一步直接写优化版本。

第七步：优化（可选）

DP优化的本质是对代码做等价变形，确保优化前后运行结果完全一致。

常见优化方式：

  • 滚动数组/降维：如果 (f[i]) 只依赖 (f[i-1])，可以把第一维去掉
  • 一维数组的循环顺序：
    • 01背包：体积从大到小循环（确保用的是上一层的值）
    • 完全背包：体积从小到大循环（确保用的是当前层的值）
  • 前缀和优化：区间和用前缀和 O(1) 计算
  • 单调队列优化、斜率优化等高级技巧

关键技巧与常见陷阱

记忆口诀

  • 状态表示 → “化零为整”：一类方案用一个数表示
  • 状态计算 → “化整为零”：找最后一个不同点拆分子集

常见错误

  1. 跳过中间步骤：直接从题目跳到优化代码，中间推导缺失
  2. 集合定义模糊：到底是 “≤j”、”=j” 还是 “≥j”？必须明确
  3. 忘记判断子集是否存在：如背包问题中 (j < v_i) 时”选第i件”的子集为空
  4. 循环顺序错误：一维优化后搞反 01背包（从大到小）和完全背包（从小到大）

  3. 按模型分类积累：背包模型、序列模型、区间DP、状态压缩DP、树形DP、状态机模型等
