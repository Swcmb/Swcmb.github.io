P1216 [IOI 1994 / USACO1.5] 数字三角形 Number Triangles

闫氏DP分析法

核心口号：化零为整定状态，化整为零推转移。

一、问题本质分析

确认是有限集合中的最优化问题

给定一个行数为 $r$ 的数字三角形，要求找一条从顶部到底部任意位置的路径，使得路径上所有数字之和最大。每步只能走到左下方或右下方的相邻点。

  • 方案总数有限：行数 $r \le 1000$。从第 $1$ 行走到第 $r$ 行，每步有 $2$ 种选择（除了边缘），总路径数是有限的（$\le 2^{r-1}$ 条）。
  • 目标属性：求的是 最大值（max），即「所有可能路径数字和中的最大者」。
  • 结论：这是一个有限集合上的 最值型 DP 问题，属于经典的「数字三角形 / 数塔」模型。

二、状态表示（化零为整）

把有相似点的方案归为一个子集，用一个状态 $f[\ldots]$ 表示。

2.1 集合定义

状态：$f[i][j]$ 表示

所有满足以下条件的方案的集合：

  1. 从顶点 $(1, 1)$ 出发，按照「左下方或右下方」的规则走；
  2. 最终落点恰好是第 $i$ 行第 $j$ 列的位置；
  3. 路径上数字之和。

记 $a[i][j]$ 为三角形第 $i$ 行第 $j$ 列位置上的数字。三角形共 $r$ 行，第 $i$ 行有 $i$ 个数字，即列号 $j$ 的取值范围为 $1 \le j \le i$。

2.2 属性确定

本问题要求的是路径上数字之和的最大值，属性为 max（最大值）。

关于 max 属性的「不重复」要求：求最大值时，子集可以有重叠——因为 $max(子集A, 子集B)$ 不要求子集互不相交，重复不影响最终结果。关键是要保证 不遗漏（所有方案都被覆盖到）。

三、状态计算（化整为零）

把 $f[i][j]$ 对应的集合划分为若干子集，分别求值后合并。

3.1 寻找最后一个不同点

到达位置 $(i, j)$ 的不同路径，其区别在于 最后一步是从哪个位置走过来的。根据移动规则（只能走左下方或右下方）：

  • 到达 $(i, j)$ 的前一个位置只能是 $(i-1, j-1)$（从左上角走右下） 或 $(i-1, j)$（从正上方走左下）。

这就是划分集合的「最后一个不同点」。

3.2 划分子集

将 $f[i][j]$ 的合法路径集合按最后一步的来源划分为两类：

子集 描述 来源状态
子集① 最后一步从 $(i-1, j-1)$ 走到 $(i, j)$ $f[i-1][j-1]$
子集② 最后一步从 $(i-1, j)$ 走到 $(i, j)$ $f[i-1][j]$

3.3 计算每个子集的值

对于 子集①：

  • 该子集中的每条路径：先到达 $(i-1, j-1)$，和记为 $S$；再走到 $(i, j)$，加上 $a[i][j]$。
  • 总路径和 = 到达 $(i-1, j-1)$ 的最大和 $+ a[i][j]$。
  • 因此子集①中的最大和为 $f[i-1][j-1] + a[i][j]$。

对于 子集②：

  • 该子集中的每条路径：先到达 $(i-1, j)$，再走到 $(i, j)$，加上 $a[i][j]$。
  • 因此子集②中的最大和为 $f[i-1][j] + a[i][j]$。

3.4 关于子集的存在性

子集①存在的前提是 $(i-1, j-1)$ 是三角形内的合法位置，即 $j-1 \ge 1$，即 $j \ge 2$。

子集②存在的前提是 $(i-1, j)$ 是三角形内的合法位置，即 $j \le i-1$。

换句话说：

  • 对于每行的最左列（$j=1$），只存在子集②（没有左上来源）；
  • 对于每行的最右列（$j=i$），只存在子集①（没有正上来源）；
  • 对于中间列（$2 \le j \le i-1$），两个子集均存在。

这也是数字三角形中 边界位置只有一个转移来源 的原因。

四、边界条件

一切以状态定义为准绳——$f[i][j]$ 表示从顶点走到 $(i,j)$ 的最大和。

  • $f[1][1] = a[1][1]$：三角形的顶点，到达它只有「站在起点」这一种方案，路径和就是 $a[1][1]$。
  • 对于位置 $(i, j)$ 不合法的情况（如 $j < 1$ 或 $j > i$），$f[i][j]$ 视为 $-\infty$（不影响 max 比较）。

五、循环顺序

状态 $f[i][j]$ 依赖于 $f[i-1][j-1]$ 和 $f[i-1][j]$，这两个状态都在上一行。因此从第 $1$ 行开始逐行向下计算即可：

  • 外层循环 $i$ 从 $2$ 到 $r$（行号递增）；
  • 内层循环 $j$ 从 $1$ 到 $i$（列号按行内顺序）。

计算 $f[i][j]$ 时，第 $i-1$ 行的所有状态已经计算完毕，依赖关系得到满足。

七、复杂度分析

指标 数值
状态数 $O(r^2)$（三角形共 $\frac{r(r+1)}{2}$ 个位置）
每状态的转移 $O(1)$（最多比较两个来源）
总时间复杂度 $O(r^2)$
空间复杂度 $O(r^2)$（二维数组）

空间优化：由于 $f[i]$ 行只依赖于 $f[i-1]$ 行，可以使用滚动数组将空间优化至 $O(r)$。此外，还可以采用逆序更新技巧，用同一个一维数组完成计算（注意内层循环 $j$ 必须从 $i$ 递减到 $1$，以确保使用的是上一行的值）。
