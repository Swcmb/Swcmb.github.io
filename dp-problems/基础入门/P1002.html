P1002 [NOIP 2002 普及组] 过河卒

题目描述

棋盘上 $A$ 点有一个过河卒，需要走到目标 $B$ 点。卒行走的规则：可以向下、或者向右。同时在棋盘上 $C$ 点有一个对方的马，该马所在的点和所有跳跃一步可达的点称为对方马的控制点。因此称之为“马拦过河卒”。

棋盘用坐标表示，$A$ 点 $(0, 0)$、$B$ 点 $(n, m)$，同样马的位置坐标是需要给出的。

现在要求你计算出卒从 $A$ 点能够到达 $B$ 点的路径的条数，假设马的位置是固定不动的，并不是卒走一步马走一步。

输入格式

一行四个正整数，分别表示 $B$ 点坐标和马的坐标。

输出格式

一个整数，表示所有的路径条数。

说明/提示

对于 $100 \%$ 的数据，$1 \le n, m \le 20$，$0 \le$ 马的坐标 $\le 20$。

保证起点不是马的控制点。

【题目来源】

NOIP 2002 普及组第四题

闫氏DP分析法

核心口号：化零为整定状态，化整为零推转移。

一、问题本质分析

确认是有限集合中的最优化问题

本题要求计算从 $(0,0)$ 到 $(n,m)$ 的合法路径总数（避开马的控制点），且每次只能向下或向右走一步。

  • 方案总数有限：网格大小 $n, m \le 20$，所有可能的路径（即便不避马）也是有限的组合数 $\binom{n+m}{n}$，方案空间确定且有界。
  • 目标属性：求的是 方案数量（count），即「有多少条不同的路径」。
  • 结论：这是一个有限集合上的 计数型 DP 问题。

二、状态表示（化零为整）

把有相似点的方案归为一个子集，用一个状态 $f[\ldots]$ 表示。

2.1 集合定义

状态：$f[i][j]$ 表示

所有满足以下条件的方案的集合：

  1. 最终落点恰好是坐标 $(i, j)$；
  2. 移动过程中遵守「只能向下或向右」规则；
  3. 路径上经过的所有点都不是马的控制点。

注意：这里的「经过」既包括中间点也包括终点 $(i,j)$ 自身——如果 $(i,j)$ 本身就是马的控制点，则该集合为空（$f[i][j] = 0$）。

2.2 属性确定

本问题要求的是方案数，属性为 count（计数）。

2.3 最终答案

将题目要求的终点坐标代入状态定义即可：答案是 $f[n][m]$。

三、状态计算（化整为零）

把 $f[i][j]$ 对应的集合划分为若干子集，分别求值后合并。

3.1 寻找最后一个不同点

不同方案之间的区别在于 最后一步是从哪个格子走过来的。由于卒只能向下或向右走：

  • 到达 $(i,j)$ 的前一个位置只能是 $(i-1, j)$（从上往下走） 或 $(i, j-1)$（从左往右走）。

这就是划分集合的「最后一个不同点」。

3.2 划分子集

将 $f[i][j]$ 的合法路径集合按最后一步的来源划分为两类：

子集 描述 来源状态
子集① 最后一步从 $(i-1, j)$ 向下到达 $(i, j)$ $f[i-1][j]$
子集② 最后一步从 $(i, j-1)$ 向右到达 $(i, j)$ $f[i][j-1]$

3.3 计算每个子集的值

对于 子集①：

  • 该子集中的每条路径由两部分组成：先走到 $(i-1, j)$，再向下一步到 $(i, j)$。
  • 从 $(i-1, j)$ 走到 $(i, j)$ 的这一步是唯一且确定的（只有向下一步）。
  • 因此子集①的方案数 = 走到 $(i-1, j)$ 的方案数 = $f[i-1][j]$。

对于 子集②：

  • 同理，该子集中的每条路径由两部分组成：先走到 $(i, j-1)$，再向右一步到 $(i, j)$。
  • 因此子集②的方案数 = 走到 $(i, j-1)$ 的方案数 = $f[i][j-1]$。

关于「不重不漏」：由于最后一步方向不同（向下 vs 向右），两条路径的终点前一步位置必然不同（$(i-1,j)$ vs $(i,j-1)$），因此两个子集 互不相交。同时，到达 $(i,j)$ 的所有合法路径的最后一步必然是这两种情况之一，因此 没有遗漏。满足计数型DP的「不重不漏」要求。

3.4 马的控制点约束

如果 $(i, j)$ 本身是马的控制点，则没有任何合法路径能到达该点，$f[i][j] = 0$。

对于来源格子 $(i-1, j)$ 或 $(i, j-1)$ 是否是控制点的问题——控制点标记的是「该格子不可达」，因此 $f$ 值本身已经为 $0$，无需额外特判。唯一的例外是：如果来源格子已经在棋盘之外（$i=0$ 或 $j=0$ 时不可从上面/左边来），需要处理边界情况。

四、边界条件

一切以状态定义为准绳——$f[i][j]$ 表示从 $(0,0)$ 走到 $(i,j)$ 的路径数。

  • $f[0][0] = 1$：走到起点的方案数有且仅有 $1$ 种（站在起点不动）。
  • 若 $(0,0)$ 是马的控制点，则直接输出 $0$（题目数据保证起点不是马的控制点）。
  • 对于 $i < 0$ 或 $j < 0$ 的越界状态，值视为 $0$。

五、循环顺序

状态 $f[i][j]$ 依赖于 $f[i-1][j]$ 和 $f[i][j-1]$，这两个状态的行号/列号均小于等于当前状态。因此使用二维循环，逐行逐列递增即可：

  • 外层循环 $i$ 从 $0$ 到 $n$；
  • 内层循环 $j$ 从 $0$ 到 $m$。

计算 $f[i][j]$ 时，$f[i-1][j]$ 和 $f[i][j-1]$ 已经先被计算过，满足依赖关系。
