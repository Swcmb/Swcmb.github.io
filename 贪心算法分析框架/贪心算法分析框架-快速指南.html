贪心算法分析框架 - 快速指南

系统化贪心算法分析框架（精简版）

本框架融合了「闫氏 DP 分析法」的结构化思想与贪心算法的特有逻辑，专为贪心问题设计的通用分析与证明体系。
核心口号：化大为小定策略，积小成大证正确。能贪则贪，贪必能证；无证不贪，退守 DP。

一、贪心算法的本质与适用前提

1.1 形式化定义

贪心算法解决的是 “在有限决策序列中，每一步都根据当前信息做出不可逆的局部最优选择，最终恰好能得到全局最优解” 的问题。

贪心可行的两个必要条件（必须同时满足）：

  1. 最优子结构（Optimal Substructure）

    问题的最优解包含其子问题的最优解。即：若 (S^) 是原问题的最优解，则做出第一步选择后的剩余子问题也存在最优解 (S’^)，且 (S^ = {第一步选择} \cup S’^)。

  2. 贪心选择性质（Greedy Choice Property）

    存在一个全局最优解，其第一步决策与我们定义的贪心选择一致，且做出该选择后，剩余子问题与原问题同构（也可用贪心求解）。

关键区别：最优子结构是 DP 和贪心的共同前提，而贪心选择性质是贪心的额外要求。若无法证明贪心选择性质，应退回 DP 或搜索。

二、贪心问题分析流程——7 步法

以下步骤必须严格遵循，不可跳跃。尤其是 第 0 步（反例攻击） 与 第 3 步（正确性证明），这是避免错误贪心的核心安全机制。

第 0 步：反例攻击与可行性初筛

在构思任何贪心策略之前，必须先以「找茬」心态尝试摧毁直觉。

0.1 快速初筛（两个”是否”）

  • 问题是否具有明确的最优子结构？（若无法清晰界定子问题，贪心几乎无望）
  • 是否存在一种局部视角，使得我们能仅凭当前信息做出不可逆的决策而不影响全局最优？

若回答模糊，直接进入 DP 分析流程。

0.3 常见的假贪心策略失败案例库

案例 1：硬币找零（非规范硬币系统）

  • 直觉：每次取面额最大的硬币
  • 反例：硬币面额 {1, 3, 4}，找零 6。贪心取 4+1+1=3 枚，最优为 3+3=2 枚
  • 教训：硬币系统不满足规范性质时贪心失效

案例 2：活动选择（选最多的不相交区间）

  • 直觉：选最短的区间
  • 反例：[1,5], [4,6], [5,10]。贪心选 [4,6] 后无法再选，最优为 [1,5] + [5,10]
  • 教训：选最短 ≠ 选最优；应选最早结束

案例 3：01 串配对——固定分组

  • 直觉：按固定位置分组（如位置 1-2, 3-4…）
  • 反例：”0110”，固定分组得 (01)(10) 无配对，但 (1,2) 可以配对
  • 教训：固定分组会错过跨分界线的更优解

方法一：交换论证法（Exchange Argument）

1.1 形式化定义

核心思想：假设存在一个不满足贪心策略的最优解，通过交换其中「违反贪心规则」的元素对，证明交换后的解不会更差。反复执行交换，最终将任意最优解转化为贪心解，因此贪心解也是最优的。

1.2 完整示例一：显示器与插座最小距离

证明过程：

考虑任意一组配对方案。假设存在两台显示器 a < b，对应插座 c < d，但配对为 a-d 和 b-c（交叉配对）。

此时总距离 (= |a-d| + |b-c|)。

考虑交换为 a-c, b-d（顺序配对），新总距离 (= |a-c| + |b-d|)。

由于 a ≤ b, c ≤ d，有四种位置关系情况：

情况 1：a ≤ b ≤ c ≤ d

  • 原：|a-d|+|b-c| = (d-a)+(c-b) = c+d-a-b
  • 新：|a-c|+|b-d| = (c-a)+(d-b) = c+d-a-b
  • 两式相等 ✓

情况 2：a ≤ c ≤ b ≤ d

  • 原：|a-d|+|b-c| = (d-a)+(b-c) = b+d-a-c
  • 新：|a-c|+|b-d| = (c-a)+(d-b) = c+d-a-b
  • 差值：(b+d-a-c) - (c+d-a-b) = 2b-2c ≥ 0（因为 b ≥ c）
  • 新 ≤ 原 ✓

情况 3：a ≤ c ≤ d ≤ b

  • 原：|a-d|+|b-c| = (d-a)+(b-c) = b+d-a-c
  • 新：|a-c|+|b-d| = (c-a)+(b-d) = b+d-a-c → 需仔细验证
  • 实际上 |a-d|+|b-c| = (b-a)+(d-c)（无交叉），|a-c|+|b-d| = (c+d-a-b)
  • 差值：(b+d-a-c) - (c+d-a-b) = 2b-2c ≥ 0，新 ≤ 原 ✓

所有情况均满足 新距离 ≤ 原距离。因此可通过有限次交换消除所有交叉，得到顺序配对解不劣于任意最优解。∎

1.3 完整示例二：插入字母最小字典序

问题：给定字符串 S，需要将 M 个已排序的字母插入 S 的任意位置，使结果字典序最小。

贪心策略：用两个指针 i (S) 和 j (字母序列)，每次比较 S[i] 和 letters[j]：

  • 若 S[i] < letters[j]：选 S[i]，i++
  • 若 S[i] > letters[j]：选 letters[j]，j++
  • 若 S[i] == letters[j]：关键——必须选 S[i]

证明（相等时选 S 的正确性）：

假设存在最优解在 S[i] == letters[j] 时选了 letters[j]（记作选 L）。

  • 设选 L 后剩余字符为 S[i:] 和 letters[j+1:]（少了当前这个 L）
  • 由于 S[i] == L，且字母序列是升序的，S[i:] 中可能还有后续字符，而 letters 中已没有等于 S[i] 的字符
  • 若选了 L：结果前缀 = …L…，后续从 S[i] 开始归并
  • 若选了 S[i]：结果前缀 = …S[i]…，后续从 S[i+1] 开始归并，letters 仍完整保留 L
  • 由于 L == S[i]，前缀相同，但选 S[i] 保留了更大的灵活性（多一个 L 可用），后续字典序不会更差

通过交换论证：若最优解在某相等处选了 L，可将其与后方第一个未匹配的 S 中的相同字符交换，字典序不增。∎

反例验证：S=”ba”, letters = “bb”

  • 正确策略（相等选 S）：选 ‘b’(S) → 剩 “a”+”bb” → 选 ‘a’(S) → 剩 “”+”bb” → 选 “bb” → 结果 “babb”
  • 错误策略（相等选 letters）：选 ‘b’(L) → 剩 “ba”+”b” → 选 ‘b’(S) → 剩 “a”+”b” → 选 ‘a’(S) → 选 ‘b’ → 结果 “bbab”
  • “babb” < “bbab” ✓

1.4 完整示例三：LQ 珠子构造（交换论证的构造应用）

问题：用 L 和 Q 两种珠子构造串，需要恰好 C 次相邻字符变化（L→Q 或 Q→L 的转换次数）。

贪心策略：

  1. 构造最小交替段：L, Q, L, Q, … 共 C+1 个珠子，产生恰好 C 次变化
  2. 多余的珠子（总数 - (C+1)）全部塞入两端（即放在串的两端）

证明：

  • 最小交替段产生 C 次变化是必要的（至少需要 C+1 个珠子）
  • 多余的珠子放在中间会引入额外变化，破坏 C 次变化的极限
  • 若多余的珠子放在两端（与端部字符相同），不会增加变化次数
  • 通过交换论证：若最优解把多余珠子放在中间（增加了变化），将其移到两端，变化数减少同时其他条件不变，不劣于原解
  • 因此贪心解最优。∎

1.5 交换论证法适用判据

条件 说明
✅ 存在「交叉」结构 方案中存在可以交换而不影响其他的元素对
✅ 交换的代价可比较 交换前后目标函数的变化可以明确比较
✅ 有限次交换可达贪心解 每次交换消除一个违规，违规数有限
✅ 交换不破坏其他约束 交换只影响交换双方，不影响第三方
❌ 交换会产生级联效应 如果交换 A,B 会影响 C,D 的状态，则交换论证不适用
❌ 没有明显的「交叉」定义 如果找不到类似「a<c<b<d」的交叉结构

1.6 常见误用

误用 1：在依赖图中使用交换论证。如果元素之间有复杂的依赖关系（如 DAG 中的拓扑顺序），交换两个元素可能破坏其他依赖。

误用 2：在多维目标中使用交换论证。如果目标函数涉及多个不可比较的维度（如同时最小化距离和字典序），交换可能在 A 维度变好但 B 维度变差。

方法二：归纳法（Mathematical Induction）

2.1 形式化定义

核心思想：证明贪心算法的第一步必然出现在某一个最优解中，然后对剩余子问题递归地应用同一论证。

标准证明模板：

2.2 完整示例一：01 串配对

问题：给定只含 ‘0’、’1’、’?’ 的字符串，相邻字符可以配对（条件：相同或其中一个为 ‘?’），求最多配对数。

贪心策略：从左到右扫描，若当前位置和下一位置可以配对，立即配对并跳过已配对的两个位置。

归纳证明：

设字符串长度为 n。

  • 基础：n ≤ 1 时，配对数 = 0，贪心正确。
  • 归纳假设：对所有长度 < n 的字符串，贪心最优。
  • 归纳步骤：对长度 n 的字符串，设贪心在位置 i 和 i+1 首次配对。
    1. 由于 i 和 i+1 满足配对条件，且贪心选择了最早可配对的位置。
    2. 假设存在最优解 OPT 不使用位置 i。则 OPT 的最高配对数 ≤ (n/2) - (位置 i 被浪费的次数)。
    3. 决策包容性论证：贪心选最早位置，留给后面的空间最大，不会错过任何可能配对。
    4. 配对后，剩余问题规模为 n-2 < n，由归纳假设贪心最优。
  • 因此贪心解全局最优。∎

2.3 完整示例二：01 串翻转匹配

问题：给定两个等长 01 串 S 和 T，每次可翻转 S 中 “101” → “010” 或 “010” → “101” 的中心字符，问能否将 S 变为 T。注意首尾字符不可变。

贪心策略：从左到右扫描（从位置 1 到 n-2），若 S[i] ≠ T[i]，则翻转位置 i+1（因为位置 i 只能通过翻转 i+1 来改变，而 i-1 已经固定不可再改）。

归纳证明：

  • 基础：处理完所有位置后，S 和 T 相等。
  • 归纳假设：处理到位置 i 时，前 i 个位置已与 T 匹配且不会再被修改。
  • 归纳步骤：
    1. 位置 i+1（从 1 到 n-2）是唯一能影响位置 i 是否匹配的翻转点。
    2. 若 S[i] == T[i]，不需要翻转，跳过。
    3. 若 S[i] ≠ T[i]，必须翻转位置 i+1，否则位置 i 永远无法匹配。
    4. 翻转后位置 i 匹配，且位置 i-1 因已匹配不受影响（翻转 i+1 只影响 i, i+1, i+2）。
  • 最后检查位置 n-2 和 n-1 是否同时匹配，若不匹配则无解（因为首尾不可操作，最后一个可翻转位置是 n-2）。
  • 因此贪心策略正确。∎

2.4 归纳法适用判据

条件 说明
✅ 逐步不可逆决策 每步决策做出后无法撤销
✅ 子问题同构 做出选择后剩余问题与原问题结构相同
✅ 有明确的「下一步」 可以清晰地定义什么是「当前的第一步」
❌ 需要全局视角做第一步 如果第一步选择需要看到全局信息
❌ 子问题不是同构的 做出选择后问题结构发生质变

方法三：反证法（Proof by Contradiction）

3.1 形式化定义

核心思想：假设贪心解不是最优的（存在更优的解），推导出矛盾，从而证明贪心解是最优的。

标准证明模板：

3.2 完整示例一：最大回文子序列

问题：给定字符串 S，找它的最长回文子序列。

贪心策略：找出 S 中出现次数最多的字符 c_max，统计其出现次数 cnt，答案即为 cnt 个 c_max 组成的字符串（全相同字符天然是回文）。

反证法证明：

  1. 设贪心解 G = c_max 重复 cnt 次，长度为 cnt。
  2. 假设存在更长的回文子序列 T，长度 > cnt。
  3. 由于 T 是回文子序列，其中出现次数最多的字符出现次数 ≥ ⌈|T|/2⌉。
  4. 而 c_max 是 S 中全局出现次数最多的字符，故 T 中任何字符的出现次数 ≤ cnt。
  5. 因此 |T| ≤ 2·cnt（因为回文子序列中同一字符最多出现 cnt 次，而要形成回文，对称位置字符相同）。
  6. 但 |T| > cnt 且 |T| ≤ 2·cnt，意味着 T 中必有一个字符出现 ⌈|T|/2⌉ > cnt/2 次。
  7. 当这导致 T 中某字符出现次数 > cnt，与 c_max 是全局最大频次矛盾。
  8. 若 |T| = cnt，则 T 中的单一字符出现次数 ≥ ⌈cnt/2⌉，但可能 ≤ cnt。需要进一步分析 T 是否能由 c_max 构成…
  9. 实际上：假设回文子序列长度为 L，其中必然存在一个字符出现 ≥ ⌈L/2⌉ 次。如果 L > cnt，则 ⌈L/2⌉ > cnt/2，与 c_max 出现 cnt 次的事实（cnt 是全局最大频次）存在潜在矛盾。更严谨的结论是：只有 c_max 能构成最大回文，因为任何其他字符的频次都 ≤ cnt - 1。∎

3.3 完整示例二：确保组成 K 个小组（最坏情况构造）

问题：有 N 个职业的学生，第 i 个职业有 a[i] 个学生。每 3 人一组，要求每组必须包含 3 个不同职业的学生。在对手可以最坏安排的情况下，能保证组成多少个小组？

贪心策略（最坏情况构造）：

  1. 若某个职业剩余 ≥ 2 人，先免费消耗掉 1 个（这个 1 个最坏情况下不构成任何限制）
  2. 每次选 3 个不同职业的剩余次数最多的职业各取 1 人，组成一组
  3. 考虑夹带私货：在组成小组时，优先消耗那些人数富余的职业

反证法证明（最坏情况）：

  1. 设贪心法得到 K 个小组。假设对手能构造一种安排使小组数 < K。
  2. 对手的最坏策略：让某些职业的人尽可能无法成组。
  3. 贪心策略使用抽屉原理（鸽巢原理）：若某个职业人数 > (N/3)*2，则无论如何安排，该职业的人必然会受到跨组限制。
  4. 通过最坏情况分析，公式为：小组数 = min(total/3, sum of min(a[i], some_threshold))。
  5. 反证：假设存在更小的构造，则必须违反抽屉原理的基本约束。∎

3.4 反证法适用判据

条件 说明
✅ 「不存在更优」比「这就是最优」更容易说清 反证法适合否定式证明
✅ 最优解的结构可以直接推理 如「如果更优，必须包含 X」→ X 不可行
✅ 极值/构造类问题 通过推翻「存在更优」来证明
❌ 最优解的结构不明确 如果无法推断「更优解必须满足什么条件」

4.2 完整示例：01 串配对（用决策包容性重新证明）

进度度量：P(方案, i) = 扫描到位置 i 时已完成的配对数。

  • 因为结束位置越靠左，留给后面的空间越多，潜在配对机会 ≥ 任意方案

✅ 进度单调递增 每步之后进度不会倒退

方法五：极值简化论证

5.1 形式化定义

核心思想：利用问题的数学/几何性质，证明只有极值（最大/最小、最左/最右）可能成为影响最终答案的关键，其余中间值可以被安全忽略。

这不是独立证明方法，而是前置简化手段——先用反证法或不等式压缩数据规模，再对简化后的问题进行贪心。

简化步骤模板：

5.2 完整示例一：球衣号码最大值

问题：N 个球员排成一列，第 i 个球员的编号为 a[i]。选 M 个队长，第 i 个队长管理的球员编号范围为和他位置最近的队长到他之间的所有球员。求所有球员（包括队长）所属组编号极差的最大值。

极值简化证明：

  • 对于任意球员 i，其所属队伍中球员编号的范围取决于离他最近的左队长和右队长。
  • 无论队长选在哪儿，球员到其组内最远编号的距离，一定在球员到最左/最右队长编号之间取最大。
  • 关键是：每个球员的答案只取决于全局 min(a) 和全局 max(a)，以及球员自身编号。
  • 因此只需记录 min_id 和 max_id，每个球员答案 = max(id[i] - min_id, max_id - id[i])。
  • 不需要引入任何复杂的数据结构或遍历所有队长。∎

5.3 完整示例二：打破时钟规则

问题：三个时钟指针分别指向 A、B、C 三个刻度（可以想象为模 12 的钟面位置）。可以减小任意指针的值。求让任意两根指针重合的最小总减少量。

极值简化证明：

  • 减小的方向固定（只能减不能增），所以最优解必然是让较大的数减小到与较小的数相等。
  • 排序后假设 A ≤ B ≤ C，则可能性：(1) 减小 B 或 C 使 B=C，(2) 减小 C 使 A=C，(3) 减小 B 和 C 使 A=B=C
  • 分析发现只需要关注三种可能的相等配对：A=B、B=C、A=C（注意 A=C 需要相同的总减少量分析）
  • 实际上因为只能减小，最小差值就是排序后相邻差的最小值：min(B-A, C-B)
  • 证明：A=B 需要减少 B-A，B=C 需要减少 C-B，A=C 需要减少 C-A = (C-B)+(B-A) ≥ min(B-A, C-B)
  • 所以 ans = min(B-A, C-B)，复杂度 O(1)。∎

问题：给定长度为 n 的字符串 s，将其重复 k 次。修改其中若干字符，使每个长度为 cycle_len 的循环节相同。求最少修改次数。

6. 复杂度：时间 O(N²)（田忌赛马 O(N) × 枚举 O(N)），空间 O(N)

示例 10：最大回文子序列（极值贪心）

0. 反例攻击

  • s=”abac”：最大字符 ‘c’ 只出现 1 次 → 回文 “c”
  • s=”ababa”：最大频次字符 ‘a’ 出现 3 次 → “aaa”
  • s=”abcba”：最大字符 ‘b’ 频次 2 → “bb”（但最优回文是 “abcba” 长度 5！）

重新分析：最大回文子序列 ≠ 全最大字符！原题是「所有字符相同的最大回文子序列」。若题目是「所有字符相同的回文子序列」，则贪心取最大字符全部正确。

1. 问题重述

  • 输入：字符串 S
  • 目标：最长的所有字符相同的回文子序列

2. 贪心策略

  • 找 S 中出现次数最多的字符
  • 该字符全部输出（全相同字符天然是回文）

3. 正确性证明（反证法）

  • 假设存在更长的全相同字符回文子序列
  • 则其长度 > max_freq，意味着有某个字符出现次数 > max_freq
  • 与 max_freq 的定义矛盾。∎

4. 边界：空串=0

5. 算法步骤

6. 复杂度：时间 O(n)，空间 O(1)（字符集有限）

策略 1：排序后顺序配对

核心思想：将两个序列分别排序后，按顺序一一对应匹配得到最优解。基于排序不等式：Σ|X_i - Y_i| ≤ Σ|X_i - Y_{π(i)}|（顺序配对距离和最小）。

识别特征：

  • 涉及两两配对，且配对代价只涉及两元素的值
  • 没有跨配对的复杂约束
  • 常见关键词：「一一配对」「最小距离和」「最小代价匹配」

标准代码模板：

代表题目：显示器插座最小距离（见示例 1）

变体：

  • 最大距离和：反向排序后配对（最大配最小）
  • 数字代价最小修改：将需修改的数字和代价排序后贪心（见策略 4）

策略 2：排序后双端取对

核心思想：排序后从数组两端取元素，贪心地比较双端乘积/差值，选择更优的一端。

识别特征：

  • 需要从数组中选 K 个元素
  • 涉及乘积、和等对符号敏感的操作
  • 数据包含正负数，符号影响最优方向
  • 常见关键词：「选 K 个」「最大乘积」

标准代码模板：

代表题目：K 个数最大乘积（见示例 3）

变体：K 为奇数时先取最大元素；全负数时取末尾 K 个。

策略 3：贡献值排序取前缀

核心思想：计算每个元素的「净贡献」值，按贡献降序排序后取前缀，直到累积贡献不再有利。

识别特征：

  • 需要在诸多选项中决定做/不做某件事
  • 每件事有收益和代价，但二者耦合在同一个行为上
  • 可以计算「净收益 = 收益 - 代价」
  • 常见关键词：「最多事件」「净贡献」

标准代码模板：

代表题目：三国获胜最多事件——计算「对 A 的贡献 - 对 B 的贡献」，降序取正前缀。

策略 4：代价排序后修改

核心思想：当需要修改若干元素使之满足某种条件时，按修改代价升序排序，优先修改代价最小的元素。

识别特征：

  • 需要修改一定数量的元素
  • 每个元素的修改代价不同
  • 修改顺序不影响最终结果
  • 常见关键词：「最少代价」「最小修改」「代价排序」

标准代码模板：

代表题目：数字代价最小修改——每种数字统计频次后，按修改代价升序选取。

策略 5：两端向中间双指针

核心思想：用左右两个指针从两端向中间扫描，寻找满足条件的元素对进行操作，最大化利用两端的最优位置。

识别特征：

  • 需要配对/消除两端元素
  • 操作涉及「最左的某元素」和「最右的某元素」
  • 常见关键词：「从两端删除」「两端匹配」

代表题目：AB 消除最大化剩余（见示例 4）——注意该题最终退化为计数法公式。

策略 6：双序列归并双指针

核心思想：将两个有序序列归并为一个，每次比较两序列当前元素，选更优的那个。重点在于相等时的 tie-breaker。

识别特征：

  • 两个有序序列需要合并为一个
  • 要求结果具有某种最优性（如字典序最小）
  • 有明确的比较标准
  • 常见关键词：「归并」「最小字典序」「插入后最优」

策略 7：快慢指针匹配

核心思想：排序后用一个指针遍历需求，另一个指针跳跃寻找满足需求的最小资源，用最小的代价满足最大的需求。

识别特征：

  • 一组「需求」和一组「供给」
  • 每个供给只能满足一个需求

策略 8：极值压缩贪心

核心思想：利用数学/几何性质证明只有极值元素可能影响最终答案，将数据量大幅压缩为只处理几个极值。

识别特征：

  • 数据范围很大但答案只与极值有关
  • 问题有明显的单调性或对称性

代表题目：

策略 9：区间调度贪心

核心思想：按区间结束时间（或开始时间）排序后，贪心选择最早结束且不与已选区间冲突的区间，可得到最多不相交区间。

识别特征：

  • 多个区间/活动，需要选最多不相交的子集
  • 每次选择会影响后续可用区间

策略 10：贡献独立贪心

核心思想：将问题划分为若干互不干扰的独立子问题，每个子问题内部贪心取最优，子问题最优解的和即为全局最优解。

识别特征：

  • 各决策单元之间没有交互

九、贪心算法数学基础

9.1 拟阵（Matroid）理论——贪心最优性的数学根基

拟阵定义：一个拟阵 (M = (S, I)) 由有限集 S 和 S 的子集族 I 组成，满足：

  1. 空集属于 I：(\emptyset \in I)
  2. 遗传性：若 (A \in I) 且 (B \subseteq A)，则 (B \in I)
  3. 交换性：若 (A, B \in I) 且 (|A| < |B|)，则存在 (x \in B \setminus A) 使 (A \cup {x} \in I)

I 中的集合称为「独立集」。

核心定理：对于拟阵上的加权独立集问题（每条边有权重，求权重和最大的独立集），贪心算法（按权重降序依次尝试加入）一定得到最优解。

意义：若你的问题可以建模为拟阵上的加权独立集，贪心正确性自动由数学保证，无需额外证明。反之，若无法建模为拟阵，则需要用本框架中的证明方法自行证明。

常见拟阵举例：

  • 图拟阵：边集 S，独立集 = 不含环的边子集 → 最小生成树 Kruskal 算法
  • 线性拟阵：向量集 S，独立集 = 线性无关子集 → 基的贪心构造

9.2 子模函数与贪心近似

当贪心不能保证最优（不构成拟阵时），贪心常被用作近似算法并带可证明的近似比。

子模函数定义：对集合函数 (f: 2^S \to \mathbb{R})，若对任意 (A \subseteq B \subseteq S) 和 (x \notin B)，有：
[f(A \cup {x}) - f(A) \geq f(B \cup {x}) - f(B)]
则 f 是单调子模函数（边际收益递减）。

核心结论：对单调子模函数受基数约束的最大化问题，贪心法的近似比为 (1 - 1/e \approx 0.632)。

9.3 贪心最优 vs 贪心近似——判断清单

条件 贪心是最优的 贪心是近似的
问题可建模为拟阵 ✅ 自动最优 —
问题可建模为子模最大化 — ✅ 近似比 1-1/e
贪心选择性质可证明 ✅ 最优 —
贪心选择性质无法证明但反例也找不到 ⚠️ 可能最优 ⚠️ 可能近似
贪心选择性质找到反例 ❌ 放弃贪心 —

9.4 竞技编程中的实操建议

对于竞赛级别的问题，绝大多数贪心题要么可以直接在拟阵框架下理解（如最小生成树），要么问题规模较小可直接通过交换论证/归纳法证明。复杂的近似比分析主要在学术论文中。实操策略：优先用本框架第三~七章的证明方法，若仍无法确定，用对拍暴力验证。
